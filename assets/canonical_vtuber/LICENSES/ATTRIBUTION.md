# Asset Attribution

This directory contains placeholder files for the canonical VTuber template assets.

## Future Assets

When populated, this directory will contain assets derived from MakeHuman CC0
assets or similar public domain sources.

## License

All assets in this directory are intended to be licensed under:
- **CC0 (Creative Commons Zero)** - Public Domain Dedication
- Or the project's main MIT license

## Attribution

If using MakeHuman CC0 assets in the future, attribution should include:

```
This project uses assets from MakeHuman (http://www.makehumancommunity.org/),
licensed under CC0 (Creative Commons Zero) - Public Domain Dedication.
```

## Note

The actual template mesh, landmark mappings, and bone definitions will be
generated by the `tools/build_canonical_template.py` script during setup.
