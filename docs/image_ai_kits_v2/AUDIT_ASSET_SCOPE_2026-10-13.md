# 24개 이미지 AI ZIP의 엔진·자산 혼입 전수 점검 (2026-10-13)

**범위:** `docs/image_ai_kits_v2/zips/`의 6모드×4자산 총 24개 ZIP, ZIP당 기존 14개 MD(총 336개 내부 문서). 이번 점검은 제작 지시서의 **서로 다른 자산/모드 실행 지시 혼입, 제작 순서의 충돌, 과한 가이드 산출 요구**를 검토한다. 이 문서는 실제 이미지 AI 출력/리깅 품질 인증이 아니다.

## 발견된 실제 문제와 기준

1. `live2d_upper__body`·`inochi2d_upper__body`가 **상반신을 전신 원화에서 크롭**하도록 하고 **전신 참고 가이드까지 새로 납품**하게 함. 수정 후에는 6등신 캐릭터의 상대 디자인만 참고하여 실제 상반신 원화를 처음부터 완성하고 `upper_body_proportion_guide.png`만 그린다.
2. 바스트업 헤어·의상·액세서리 최상위 지침이 **머리·목·어깨 비율을 재설계하고 안전 가림용 몸체를 신규 제작**하도록 읽힐 수 있음. 수정 후에는 기존 신체를 **좌표 참조**로만 사용하고 요청된 자산 하나만 제작한다.
3. 전신 신체 ZIP에는 **상반신 크롭·상반신만 납품**이라는 다른 모드 문구가 혼입됨. 전신 원화와 전신 6등신 기준은 그대로 유지하면서 해당 문장만 제거했다.
4. 3D 헤어·의상·액세서리 공식 참고자료가 **신체 눈·코·입·손 상세도**까지 각각 그리라고 요구함. 수정 후에는 소유 자산만 독립 4방향으로 그린다.
5. 2D 공식 참고자료는 Live2D/Inochi2D를 한꺼번에 열거했고 3D 참고자료는 2D 원화 분리 자료와 외부 엔진 기능을 섞었다. `05_OFFICIAL_REFERENCES.md` **24개 모두** 선택한 엔진/자산의 자료로 재작성했다. 후속 Editor/VRM/물리 작업은 그대로 제외했다.
6. 재생성용 `ADVANCED_VERIFIED_2D.md`에는 **처음부터 파츠만 생성**하는 옛 지시가 남아 **완성 원화 먼저**와 충돌했으며, `MODE_2D.md`와 `ADVANCED_VERIFIED_3D.md`에는 화면 밖 신체 부위/다른 자산의 상세도까지 요구하는 문구가 있었다. 공통 원본과 2D·3D 입력 스냅샷에서 수정했다.

## 수정 이후 유지하는 제작 계약

- 신체 전신은 **프로젝트 6등신**. 상반신은 두상·어깨 상대 비율만 참조하고 실제 상반신 원화부터 제작. 바스트업은 방송 프레임에 필요한 영역만 제작한다.
- 2D는 **해당 자산 완성 원화 먼저 → 실제 필요한 파츠만 분리·숨은 면 보완 → 동일 캔버스/알파 재합성**. 3D는 **해당 자산 정면 원화 → 후면/좌우 독립 작화**이며 2D 레이어/PSD/리깅 지시를 요구하지 않는다.
- 눈·홍채·입·피부·목은 신체, 모근·가닥은 헤어, 옷감·카라·소매·고정 의상 장식은 의상, 요청된 소품 본체·고정부는 액세서리 소유다. 다른 자산 그림은 **참조만** 할 수 있다.
- 원래 있던 숨은 픽셀 보완, 셀 채색, 그림자 소유권, 소재·선폭, 시점 정합, 7개 고급 전문 문서의 내용은 유지한다. 무관한 자산을 만들지 않으며 결과 ZIP당 14개 제작 지시 문서를 유지한다.

## 재발 방지

- [엔진·자산 공식자료 원본](source/ASSET_SCOPED_OFFICIAL_REFERENCES.json)은 3엔진×4자산의 12가지 조합을 분리하고, 파일 내부에서도 6모드×4자산에 맞춰 배치한다.
- [ZIP 재생성 동기화](../../tools/sync_image_ai_geometry_guidance.py)의 `--check`는 24개 내부 공식 참고문서가 각각 자신의 모드·자산과 정확히 일치하는지 확인한다. `--write`는 다른 자산으로 섞인 05번 문서만 공식 원본에 맞춰 복구한다.
- [범위 혼입 회귀 검사](../../tests/test_image_ai_kits_full_scope_audit.py)는 모든 ZIP의 14개 구성/CRC, 제작 범위와 공식 참고자료, 2D/3D 원본 스냅샷, 재생성 후 자동 복구를 확인한다.

**검사 한계:** 이 기록은 문서의 의미·산출 대상과 ZIP 구조를 점검한 결과다. 외부 이미지 모델이 실제로 그린 원화·투명 PNG의 미술 완성도와 Live2D/Inochi/3D 실제 모델링 품질을 검증했다고 주장하지 않는다.
