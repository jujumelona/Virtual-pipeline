## 핵심: 턱–목–어깨를 실제로 그리는 법

1. 얼굴 바탕은 이마·관자놀이·볼·짧고 둥근 턱까지 완성하며 눈·입·귀·목을 합치지 않는다.
2. 목의 윗단을 **턱과 귀 뒤에 가려질 부분까지 실제 동일한 피부색**으로 채워 그린다. 얼굴을 끄면 목 윗단이 남아 있어야 한다.
3. 목의 아랫단은 어깨·몸통 안쪽 아래까지 끊기지 않게 그린다. 몸통을 끄면 숨은 목의 아랫단이 보여야 한다. 숨는 절단 경계에 검은 외곽선을 그리지 않는다.
4. 몸통은 턱/목 뒤와 겨드랑이·어깨를 받치는 단색 불투명 클레이 색면으로 그려서 접합 부위가 투명하게 비지 않게 한다.
5. 실제 측면 그림은 코끝→입→턱끝, 귀 아래→뒷목, 턱 뒤→목 앞선→어깨까지 이어지는 **새 측면 실루엣**이어야 한다. 정면 얼굴이나 목을 좌우로 옮기거나 가로로 누른 결과는 실패다.
6. 얼굴/목/몸통을 따로 숨겨 감춰진 피부의 실제 RGB 픽셀을 눈으로 확인한다. 최종 중립 합성에서 투명 삼각형·턱 밑 검정 이중선·떠 있는 목을 금지한다.
7. 측면 참조 PNG만으로 실제 90도 Native Cubism/Inochi2D 회전이 구현되는 것은 아니다. 실제 디포머/키폼/가림 변형은 후속 모델링과 네이티브 렌더 검사 대상이다.

## 제작 책임 구분

**이미지 AI:** 실제 원화·템플릿 시각 참조 → 한 번에 파츠 하나씩 같은 캔버스 RGBA 그림을 직접 생성 → 숨은 연결 면 복원 → 참조 시점 실제 그림 → 중립 합성 비교.

**후속 Colab:** 독립 RGBA·순서·마스터 합성 검증 → PSD 조립 → 해당 Live2D/Inochi2D/3D 엔진으로 모델 변형·리깅 → 네이티브 포즈/표정 실제 렌더 검증.

**검증하지 못한 부분:** 실제 이미지 AI로 새로운 캐릭터를 모두 생성한 결과, 템플릿 레이어 그림의 원본 파일 열람 증거, native MOC3/Inochi Puppet 또는 3D 메시 동작은 이 단계에서 인증한 것이 아니다. 문서·ZIP 수정 완료와 모델 제작 완료를 혼동하지 않는다.
