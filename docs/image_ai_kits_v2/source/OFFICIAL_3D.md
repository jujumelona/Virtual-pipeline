# 3D 공식 배경 인덱스 — 자산별 참조 자료만 개별 ZIP에 반영

이 파일은 공식 링크의 내부 색인이다. **신체·헤어·의상·액세서리의 3D 그림 제작 의무를 한 문서에서 모두 요구하지 않는다.** 실제 배포 ZIP의 `05_OFFICIAL_REFERENCES.md`는 `source/ASSET_SCOPED_OFFICIAL_REFERENCES.json`의 `3d.body/hair/outfit/accessory`에 정의된 자산별 근거만 사용한다.

- VRM 공식 Humanoid (신체 모델링의 후속 배경): https://vrm.dev/en/vrm1/humanoid/
- VRM SpringBone (헤어·의상의 실제 유연 부속·소품 체인이 존재할 때만 후속 참고): https://vrm.dev/en/vrm1/springbone/
- VRM 공식 기능 (후속 3D 재질/표현): https://vrm.dev/en/vrm/vrm_features/

이 ZIP들의 납품물은 **요청된 자산 하나의 정면/후면/좌측/우측 참조 그림과 그 자산의 세부도**다. 실제 메시·UV·VRM·본·물리를 생성하지 않는다. 신체 외 자산에는 눈/코/입/손/발 상세를 그리라고 요구하지 않는다.
