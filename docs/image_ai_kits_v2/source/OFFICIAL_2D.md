# 2D 공식 근거 인덱스 — ZIP에는 엔진·자산별 발췌만 사용

이 파일은 원본 제작 지식의 분류표다. **서로 다른 엔진의 내용을 섞어서 개별 ZIP 05_OFFICIAL_REFERENCES.md로 복사하지 않는다.** 각 ZIP에서 사용해야 할 공식 근거는 `source/ASSET_SCOPED_OFFICIAL_REFERENCES.json`의 **live2d/inochi2d × body/hair/outfit/accessory**에 따로 정의돼 있다.

- Live2D 공식 그림 분리: https://docs.live2d.com/en/cubism-editor-tutorials/psd/ — 해당 ZIP의 파츠 원화만 분리·가림 보완에 참고
- Inochi2D 공식 PSD 예제: https://docs.inochi2d.com/en/latest/creator/first-model/tutorial01.html — 해당 ZIP의 중립 합성/그림자 겹침 주의, 노드 작업은 후속
- Live2D 공식 PSD 주의사항: https://docs.live2d.com/en/cubism-editor-manual/precautions-for-psd-data/ — 후속 Editor 준비 참고자료로만 사용

완성 기준 원화를 먼저 만든 후 필요 파츠만 추출·보완한다. 신체/헤어/의상/단일 소품은 절대 하나의 납품 세트로 합치지 않는다. 엔진 가져오기/PSD 처리/리깅을 이미지 AI에 강제하지 않는다.
