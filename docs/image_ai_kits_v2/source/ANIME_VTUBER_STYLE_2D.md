# 2D 전문 VTuber 애니풍 원화 스타일 — 전 모드/자산에 우선 적용

**기본 미술 방향은 반드시 고품질 일본 애니메이션풍 Live2D/VTuber 일러스트**다. 사용자가 다른 명확한 그림 스타일이나 스타일 참조를 주면 사용자의 디자인을 우선한다. 애니풍이라는 단어 한 번으로 끝내지 말고 다음 원화 규칙을 처음부터 각 파츠 생성 호출에 적용한다.

## 1. 선화와 진한 외곽선 — 중요
- 외형 테두리는 **짙은 잉크 계열(검정에 가까운 다크 브라운/다크 퍼플/다크 그레이)**의 **선명하고 깔끔한 외곽선**으로 묘사한다. 필요 시 검정색 사용 가능. 흐릿한 회색 경계, 실루엣이 풀리는 라인, 뭉툭한 벡터 테두리를 금지한다.
- **바깥 실루엣과 눈 윗속눈썹은 상대적으로 진하고 굵게**, 눈 안쪽·코·피부 주름·입가·머리 내부의 보조선은 더 얇고 부드럽게. 약 **실루엣 선 두께가 세부선의 1.5~2.5배** 정도가 출발점(절대 픽셀 규격 아님). 선이 끝날 때 **가늘게 빠지는 tapered line endings**, 곡선·겹침에서는 세밀하게 강약 변화.
- 피부 내부는 **순수 검정 가로선/동그라미로 코나 입을 둘러싸지 않는다**. 피부에서 짙은 피부색·부드러운 갈색, 머리에서는 모발의 암색을 쓰는 **색이 있는 내곽선(colored inner lineart)**도 사용한다.
- **선화 안티앨리어싱, 경계의 번짐·들뜸 제거**. 여러 독립 PNG를 합쳤을 때 선 굵기·진한 색·선 연결이 하나의 전문 애니 일러스트처럼 이어져야 한다.

## 2. 얼굴·눈·입
- 일본 애니 캐릭터의 **일관된 눈 크기, 예쁜 눈매/곡선형 눈꼬리, 진한 테이퍼 윗속눈썹**, 하단은 더 가는 선화. 눈동자에 **다층 색/홍채 방사 질감, 위쪽 음영과 1~3개 자연스러운 반사광**(반사광이 독립적으로 움직여야 한다면 파츠 분리).
- 코는 스타일에 맞게 **작고 섬세한 선·그림자**, 입도 작고 정갈하게; 성급한 검은 타원 구멍이나 만화 이모티콘 곡선을 입으로 대신하지 않는다. 입술·입안·혀는 움직임에 필요하면 처음부터 개별 원화.
- 피부는 기본색 + **턱/귀/눈꺼풀/코 아래에 부드러운 음영**, 필요한 볼터치·얕은 광을 섬세하게. **셀 셰이딩의 깔끔한 명암 색면**을 기본으로, 주변에 **절제된 부드러운 그러데이션**을 혼합할 수 있다.
- 헤어 없는 **신체만** ZIP도 얼굴 품질을 낮추지 않는다. 머리는 나중 헤어 파츠를 장착하기 위한 민머리 베이스지만 **고급 애니 얼굴**이어야 한다. 가짜 머리카락·헤어라인을 임의 생성하지 않는다.

## 3. 헤어·의상·액세서리
- 헤어: 실루엣이 다각형 빗자루처럼 뭉치지 않게 **크고 작은 머리카락 묶음의 리듬**, 가느다란 속선, 뿌리→끝으로 흐르는 방향성, 짙은 그림자·좁은 반사광을 자연스럽게 그린다. 앞/옆/뒤의 독립 움직임이 필요한 덩어리는 완성 헤어 원화에서 분리하고 숨은 부분을 추가 작화한다.
- 의상: 실제 의상의 솔기·접힘·장력에 따른 자연스러운 **주름 위치**, 셀 음영·원단 색 변화, 소재별 반짝임과 가장자리 선화. 소매/옷깃/리본/프릴은 실제 다르게 움직이는 경우만 별도 PNG.
- 액세서리: **사용자가 요청한 물건 한 종류만**, 작은 금속 테두리/보석/천 질감도 가독성 있게. 안경이나 머리장식 하나만으로 충분하면 추가 장식 세트 금지.

## 4. 형태·인체 비례
- 유아용 SD/치비, 벡터 인형, 2D 종이인형, 가느다란 막대 팔·풍선형 어깨·손가락 누락, '회색 긴 티셔츠=속옷' 대체 **금지**(사용자가 명시적으로 SD를 요구한 경우 제외).
- 일반적인 **애니 VTuber 상반신 비율**, 목과 어깨의 자연스러운 연결·상완/전완/손 비례·인체 관절의 유기적 형태. 신체 베이스는 불투명하고 비선정적인 기본 속옷(교체용 분리 지시 아님).
- 사용자 요청 성별·중성적 캐릭터·나이와 인상에 일관된 애니풍 표정/체형. 특정 공식 샘플 캐릭터 외형 복제 금지.

## 5. 생성 프롬프트 맨 앞에 넣을 문장

> **Commercial-quality Japanese anime VTuber character artwork, polished 2D Live2D-ready illustration, strong clean dark ink outlines, expressive tapered line weight, colored inner lineart, refined anime facial anatomy, expressive layered irises, clean 2–3 value cel shading with subtle soft skin gradients, asset-appropriate proportions and artwork (body anatomy ONLY in the body kit, hair flow ONLY in the hair kit, fabric structure ONLY in outfit, attachment structure ONLY in accessory), consistent studio-quality drawing across each extracted and completed part. Not flat vector art, not cartoon icon art, not crude mannequin, not uniformly thick black strokes.**

이 문장은 구체 스타일 요청이 없다면 신체·헤어·의상·액세서리의 **실제 이미지 생성 프롬프트에 적용**한다. 이 문구를 결과 ZIP에 넣는 것만으로 품질을 보장할 수 없으므로, 생성된 파츠와 합성 미리보기를 실제로 비교·수정한다.

- 헤어: 요청한 모발만의 볼륨·테이퍼·재질별 광택.
- 의상: 요청한 옷의 옷깃·솔기·주름/안감.
- 액세서리: 사용자 주문 하나의 실제 부착·투명/금속 재질.
