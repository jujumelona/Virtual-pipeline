# 3D 모델링용 참조 원화의 품질 기준 — 이미지 AI용

실제 3D 메시·리깅·VRM/GLB/FBX가 아니라 **고품질 다각도 시트/디자인 원화**만 생성한다. 사용자 참조 캐릭터가 있으면 그 외형·스타일을 최우선으로 고정한다. 스타일 지정이 없으면 정교한 애니메이션 캐릭터 디자인 기준으로 제작한다.

## 필수 수준
- 각 방향은 같은 캐릭터·같은 물건의 정면/후면/좌우 **별도 이미지 생성** 결과여야 한다. 관절·손·발·얼굴·헤어볼륨·옷의 치수와 재질·소품 부착 위치가 일치해야 한다.
- **인체 해부와 의복 재봉 구조가 설득력 있게 그려져야 한다.** 막대 팔·미성숙한 손·둥근 도형 얼굴·튜브 모양 몸통 등 단순한 도형 시트는 최종 3D 아트 레퍼런스가 아니다.
- 세부 그림(눈·눈썹·코·입·손·옷감·장식의 고정점)은 실제 원화로 그려야 한다. 이름만 바꾸거나 단순 크롭·미러링한 이미지 사용 금지.
- **명암·선화·형태·색상 일관성**, 정투영에 가까운 시점/균일 광원과 정렬된 기준선이 필요하다.
- **신체만**은 나체가 아닌 불투명·비선정적 기본 속옷 착용. 긴 회색 겉옷을 임의로 입혀 몸 구조를 가리지 않는다. 속옷 교체 세트는 만들지 않는다.
- 헤어·의상·액세서리는 사용자가 요청한 대상 **한 종류만** 그린다. 장식 세트 자동 제작 금지.
- 실제 이미지 생성/편집 기능을 써서 그린다. **SVG 도형·Pillow·Matplotlib로 만든 기초 기하학 그림을 정교한 캐릭터 원화라고 포장하지 않는다.** 코드 도구는 정렬·합성·ZIP 보조에만 사용.
- 결과 4면도를 나란히 놓고 **인체 비례·실루엣·높이·얼굴·색/무늬/부착 위치 불일치가 해결될 때까지 해당 방향을 재작업**한다.

## 공식·실무 자료
- [VRM 공식 Humanoid 참고](https://vrm.dev/en/vrm1/humanoid/), [VRM 표정·시선 등 기능](https://vrm.dev/en/vrm/vrm_features/)
- [Live2D 공식 샘플 원화 갤러리](https://www.live2d.com/en/learn/sample/) — 2D 캐릭터 작화의 전반적 미술 수준 참조; 3D 구현 자료와 혼동 금지.
- [Blender 공식 UV 설명](https://docs.blender.org/manual/en/latest/modeling/meshes/uv/unwrapping/introduction.html) — 이미지 원화가 실제 UV/텍스처가 아님을 확인.
- [비공식 VTuber 참조 시트 디자인 실무](https://virmii.com/blog/tutorial/how-to-make-vtuber-reference-sheet)

링크를 실제로 열지 못하면 봤다고 말하지 않는다. 이 문서는 실제 그림 제작 지시이고 모델링/리깅 검증 문서는 아니다. 정교한 원화와 형상 정합을 만족하지 못하면 최종 ZIP이라 주장하지 않는다.
