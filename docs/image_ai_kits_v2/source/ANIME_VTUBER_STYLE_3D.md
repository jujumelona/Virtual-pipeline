# 3D용 애니메이션 스타일 캐릭터 참조 그림

사용자가 별도 스타일을 요청하지 않으면 **일본 애니메이션풍 VTuber / VRoid 캐릭터 원화**를 기본으로 사용한다. 그림은 3D 메시가 아니며, 네 방향 2D 참조 그림을 만든다.

- 검정에 가까운 **선명하고 세련된 짙은 외곽선**, 너무 두꺼운 검은 벡터 테두리가 아닌 **가변 굵기/가늘어지는 테이퍼 선화**. 피부 내부는 짙은 갈색, 머리는 암색을 활용한 색선.
- **3D 모델러가 읽을 수 있는 전후좌우 실루엣**과 깊이·두께는 유지. 정면/측면에서 애니풍 눈매·얼굴 비례·머리카락 큰 묶음이 같은 캐릭터로 보인다.
- 애니풍 홍채·윤곽·작고 정교한 코/입, 눈꺼풀/입안 상세; **정확한 어깨·팔·손·발 비례**, 실무용 자세 A/T pose의 일관성.
- 깨끗한 2~3단계 **셀 셰이딩**과 제한적인 피부 소프트 명암, 머리카락의 흐름·반사광, 의상의 실제 장력/주름과 재질 대비. 조명/색을 네 시점에서 일관되게.
- **치비/SD, 막대 인간·회색 도형 바디, 단순 SVG 템플릿** 금지(사용자가 SD/그 스타일을 요청한 경우 제외). 속옷을 입은 신체 베이스는 긴 티셔츠로 덮지 않는다.
- 헤어/의상/액세서리는 사용자가 정한 그 종류만. 다른 자산 세트를 멋대로 포함하지 않는다.

**이미지 생성 호출에 적용할 영어 프롬프트:**

> **Professional anime VTuber character design turnaround, clean dark ink variable-weight outlines with tapered strokes, expressive anime face and eyes, sophisticated 2–3 tone cel shading, consistent anatomy and silhouette across independently drawn front back left and right orthographic-style reference views, high detail, crisp original illustration. No vector mannequin, no simplistic flat clipart.**

후속 3D 모델 메시·본·UV·리깅 결과를 이미지 AI에게 요구하지 않는다.
