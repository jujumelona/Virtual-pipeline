# 고급 이미지 원화 제작 공통 지시 — 모든 ZIP에 반드시 포함

이 지시서의 고객은 버추얼 캐릭터의 신체만/헤어만/의상만/액세서리만을 분리해서 주문한다. 첨부한 ZIP에 해당하는 종류 **하나만** 제작한다.

## 제작 순서 — 원화 먼저, 파츠 분리 다음 (최신 계약)

1. 사용자가 제공한 디자인·기존 베이스(있을 때)를 고정한다. 신체 제작은 선택된 **전신/일반 상반신 모드일 때** 이 프로젝트의 6등신 디자인 기준을 사용하고, **바스트업에서는 처음부터 머리~상체 윗부분의 방송용 구도**를 사용한다. 큰 애니눈과 사용자 원화의 고유 비례를 우선한다. 헤어/의상/장식 등 독립 자산은 기준 몸체에 맞춰 디자인한다.
2. 먼저 **고품질 완성 기준 원화 한 장**을 그린다. 선택된 자산 **하나**의 실루엣·선화·명암·크기가 목표 품질인지 본 뒤 파츠 작업을 시작한다. 헤어·의상·장식의 마스터 원화에 얼굴이나 신체를 새로 그려 넣지 않는다.
3. 완성 원화의 실제 보이는 부위를 움직임·가림·표정 단위로 나누어 독립 PNG로 저장한다. 가려진 영역은 **해당 자산에 속하는 것만** 같은 화풍으로 연장한다. 눈 흰자·홍채·입안·귀·목·관절은 신체, 머리뿌리는 헤어, 옷 안감은 의상, 소품의 숨은 뒷면은 액세서리에서만 생성한다.
4. 시트로 중간 생성해도 납품은 실제 분리된 각각의 RGBA PNG다. 구멍, 경계, 이중 입, 잘못된 부착 위치가 있으면 고품질 원화와 파츠를 수정한다.
5. 파츠 수는 **27개든 더 많든 숫자로 고정하지 않는다.** 실제 움직임/가림/표정에 필요한 만큼 분리하되 고정된 피부 무늬나 하나로 자연스럽게 휘는 부분을 무의미하게 쪼개지 않는다.
6. **2D에서는** 동일 캔버스·원점, 투명 RGBA와 캐릭터 본인 기준 L/R을 유지하고, 뒤→앞 목록을 `layer_order.txt`에 적는다. **3D 참조도에서는** 정면/후면/좌우 실제 그림과 동일 기준선을 사용하고 2D 파츠·레이어 파일을 요구하지 않는다.
7. **2D에서는** 실제 해당 자산 PNG를 재합성해 선화·경계·광원과 일치하는지 확인한다. **3D에서는** 별도로 그린 4방향 그림의 실루엣·좌우 의미·기준선 일치 여부를 확인한다. 마지막 합성 이미지를 다시 파츠로 잘라 제출하지 않는다. 사용자가 주문하지 않은 다른 자산을 추가하지 않는다.
8. **이미지 AI 수행 범위에 한정:** 실제 그림·투명 PNG·참조 원화·프리뷰·ZIP. PSD·Live2D Cubism/Inochi 리깅, 3D 메시·VRM·모션 테스트·자동 합격 인증은 만들었다고 주장하지 않는다.

3D 참조 ZIP에서는 해당 **자산만** 정면 마스터를 먼저 완성하고 실제 측면·후면을 그린다. 6등신 전신의 비례 기준은 신체에만 직접 적용하고 헤어·의상·장식은 제공된 몸체의 크기에 맞춰 정렬한다. 2D ZIP에서는 원화 분리와 가려진 부분의 보완을 한다. 두 경우 모두 기준 스타일의 연속성과 실제 파일 완성을 우선한다.

## 기본 신체의 중립 실루엣 — 실제 생성 계약

**유일한 BODY 제작 기준:** 성인 캐릭터를 위한 고품질 2D/3D 애니 원화를 실제 이미지 생성 AI로 제작한다. 큰 두상·크고 선명한 눈/홍채·짧고 넓은 얼굴·부드럽게 둥근 U형 턱을 유지한다. 길고 좁은 말상·긴 하관·뾰족한 V턱·실사 인체와 과한 해부학선, 회색 도형 프록시는 불합격. 기본 불투명 스포츠 수영복 상의를 모든 BODY 시점에서 착용하고 하체가 보이면 쇼츠형 하의도 착용한다. 교체 패션 의상만 OUTFIT에서 별도로 제작한다. 신체는 먼저 완성된 채색 원화로 제작하고 이후 필요한 레이어를 분리한다. 다른 자산은 제공된 BODY를 좌표 기준으로만 사용한다.

눈동자 색상은 작업마다 사용자 지정값을 우선하며 기본값을 분홍/노랑으로 고정하지 않는다. 큰 눈만으로 합격 처리하지 않고 둥근 하관(U형), 단순한 소형 귀, 정수리 비례와 짧고 단정한 목을 함께 비교한다. 공식 샘플의 **이미지를 실제로 열어** 본 뒤 눈/얼굴/귀/목 차이를 기록하며, 링크만 읽은 경우 시각검수 PASS라고 쓰지 않는다.

## 품질의 실질적 기준 (이미지 작업 내부)

신체 눈 PNG에 홍채·속눈썹 잔상이 섞이거나, 헤어 PNG에 얼굴이 붙거나, 의상의 소매 안감이 잘리거나, 액세서리가 부착점에서 떠 있으면 **문제가 발생한 해당 자산의 그림만** 수정한다. 이것은 결과 그림을 잘 그리기 위한 작업 지시일 뿐, 실제 리깅이나 자동 합격 검사까지 수행하라는 요구가 아니다.

완성품이 없는 상태에서 단순한 제작 설명문만 반환하지 않는다. 실제 이미지 제작 도구/파일 작성 도구가 없는 환경이라면 실제 만들지 않은 ZIP을 생성했다고 주장하지 않는다.
