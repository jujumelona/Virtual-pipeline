# 고급 이미지 원화 제작 공통 지시 — 모든 ZIP에 반드시 포함

이 지시서의 고객은 버추얼 캐릭터의 신체만/헤어만/의상만/액세서리만을 분리해서 주문한다. 첨부한 ZIP에 해당하는 종류 **하나만** 제작한다.

## 생성 순서 — 절대로 완성 그림부터 분리하지 않는다

1. 사용자가 제공한 디자인·기존 베이스(있을 때)를 고정한다. 기준 배치 스케치가 필요하면 **선화 가이드**만 먼저 만든다. 이것을 픽셀 추출용 완성 그림으로 사용하지 않는다.
2. 작업 종류에 필요한 가장 세밀한 **독립 움직임/가림 깊이 기준의 원화 파츠들을 각각 처음부터 그린다.** 합성 완성본을 먼저 그려 마스크·자동 분리하는 방식은 사용하지 않는다.
3. 이동하면 가려진 곳이 드러나는 원화(눈 흰자, 입안, 앞머리 아래 피부, 머리뿌리, 귀, 목, 팔·다리 관절, 옷 안감/몸통)를 처음부터 충분히 그린다. 생략한 부위가 보일 때 투명 구멍이 나면 안 된다.
4. 서로 다른 깊이/독립 움직임/표정 변화가 있으면 처음부터 별도 PNG로 그린다. 한 개의 긴 가닥처럼 자연스럽게 휘는 것은 쓸데없이 조각내지 않으며, 고정 문양도 의상과 함께 유지한다. **나중에 분리하라고 떠넘기지 않는다.**
5. AI는 필요한 경우 한 이미지 **시트에 여러 파츠를 나란히 생성**할 수 있다. 그러나 납품은 각 파츠를 진짜 투명 PNG로 따로 저장한다. 시트만 납품하지 않는다.
6. 마지막에 **실제 생성된 파츠들을 합성**해 완성 미리보기를 만든다. 미리보기를 다시 파츠로 잘라내지 않는다.
7. 가능한 경우 각 투명 PNG를 동일 기준 캔버스 크기/원점에 정렬한다. 파츠 바깥은 alpha=0이다. L/R은 캐릭터 **본인 기준**이다. 2D 결과는 뒤에서 앞으로 정렬한 파일명 목록 layer_order.txt를 함께 작성한다.
8. 사용자 지정 없는 신체·옷·머리·장신구를 마음대로 다른 자산 종류에 추가하지 않는다. 의상에 고정된 장식은 의상의 일부이고, 액세서리의 구체적인 종류는 사용자가 지정한다.
9. **이미지 AI가 실제 수행 가능한 범위에 한정한다:** 그림 생성·투명 PNG 저장·그룹 시트·합성 미리보기·ZIP 납품. PSD 작업, Cubism/Inochi Creator 리깅, 실제 3D 메시·본·VRM·물리·회전/모션 테스트나 인증서는 요청하지 않는다.

## 기본 신체의 불투명 속옷 — 노출 방지 용도

신체만 선택 시 **선정적이지 않은 불투명 기본 속옷을 입은 베이스**로 제작한다. 목적은 이미지 AI에게 **나체를 생성하라는 요청을 하지 않기 위함**이다. 속옷을 별도 분리·탈착·교체 자산으로 만들라고 요구하지 않는다. 인체 제작과 속옷 그림은 처음부터 서로 일치하는 안전한 외형으로 만든다.

## 품질의 실질적 기준 (이미지 작업 내부)

눈 PNG에 홍채·속눈썹이 뒤섞이거나, 뒤통수 PNG에 앞머리/얼굴이 함께 붙거나, 소매·관절 뒷부분이 잘린 경우에는 그 그림을 바로 다시 생성한다. 이것은 결과 그림을 잘 그리기 위한 작업 지시일 뿐, 실제 리깅이나 자동 합격 검사까지 수행하라는 요구가 아니다.

완성품이 없는 상태에서 단순한 제작 설명문만 반환하지 않는다. 실제 이미지 제작 도구/파일 작성 도구가 없는 환경이라면 실제 만들지 않은 ZIP을 생성했다고 주장하지 않는다.
