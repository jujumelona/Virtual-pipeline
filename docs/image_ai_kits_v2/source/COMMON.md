# 고급 이미지 원화 제작 공통 지시 — 모든 ZIP에 반드시 포함

이 지시서의 고객은 버추얼 캐릭터의 신체만/헤어만/의상만/액세서리만을 분리해서 주문한다. 첨부한 ZIP에 해당하는 종류 **하나만** 제작한다.

## 제작 순서 — 원화 먼저, 파츠 분리 다음 (최신 계약)

1. 사용자가 제공한 디자인·기존 베이스(있을 때)를 고정한다. 신체 제작은 해당 ZIP의 **6등신·큰 애니눈** 등 구체적 비율을 먼저 적용한다. 헤어/의상/장식 등 독립 자산은 기준 몸체에 맞춰 디자인한다.
2. 먼저 **고품질 완성 기준 원화 한 장**을 그린다. 이 원화의 얼굴·몸통·선화·음영·비율이 목표 품질인지 본 뒤 파츠 작업을 시작한다.
3. 완성 원화의 실제 보이는 부위를 움직임·가림·표정 단위로 나누어 독립 PNG로 저장한다. 눈 흰자·홍채·입안·머리뿌리·귀·목·관절·옷 안감처럼 원화에 가려진 부위는 빈 공간을 메우는 데 그치지 말고 **동일 화풍으로 새로 그려 연장**한다.
4. 시트로 중간 생성해도 납품은 실제 분리된 각각의 RGBA PNG다. 구멍, 경계, 이중 입, 잘못된 부착 위치가 있으면 고품질 원화와 파츠를 수정한다.
5. 파츠 수는 **27개든 더 많든 숫자로 고정하지 않는다.** 실제 움직임/가림/표정에 필요한 만큼 분리하되 고정된 피부 무늬나 하나로 자연스럽게 휘는 부분을 무의미하게 쪼개지 않는다.
6. 동일한 캔버스 기준 좌표·알파=0 바깥영역·L/R 캐릭터 본인 기준을 유지한다. 레이어의 뒤→앞 목록은 `layer_order.txt`에 적는다.
7. 실제 PNG를 합성해 기준 원화의 눈·머리·몸 비율/경계/광원과 일치하는지 확인한다. 마지막 합성 이미지를 다시 파츠로 잘라 제출하지 않는다. 사용자가 주문하지 않은 다른 자산을 추가하지 않는다.
8. **이미지 AI 수행 범위에 한정:** 실제 그림·투명 PNG·참조 원화·프리뷰·ZIP. PSD·Live2D Cubism/Inochi 리깅, 3D 메시·VRM·모션 테스트·자동 합격 인증은 만들었다고 주장하지 않는다.

3D 참조 원화 ZIP에서는 정면 마스터를 먼저 완성하고 같은 6등신 캐릭터에 대해 실제 측면·후면을 그린다. 2D ZIP에서는 원화 분리와 가려진 부분의 보완을 한다. 두 경우 모두 기준 스타일의 연속성과 실제 파일 완성을 우선한다.

## 기본 신체의 불투명 속옷 — 노출 방지 용도

신체만 선택 시 **선정적이지 않은 불투명 기본 속옷을 입은 베이스**로 제작한다. 목적은 이미지 AI에게 **나체를 생성하라는 요청을 하지 않기 위함**이다. 속옷을 별도 분리·탈착·교체 자산으로 만들라고 요구하지 않는다. 인체 제작과 속옷 그림은 처음부터 서로 일치하는 안전한 외형으로 만든다.

## 품질의 실질적 기준 (이미지 작업 내부)

눈 PNG에 홍채·속눈썹이 뒤섞이거나, 뒤통수 PNG에 앞머리/얼굴이 함께 붙거나, 소매·관절 뒷부분이 잘린 경우에는 그 그림을 바로 다시 생성한다. 이것은 결과 그림을 잘 그리기 위한 작업 지시일 뿐, 실제 리깅이나 자동 합격 검사까지 수행하라는 요구가 아니다.

완성품이 없는 상태에서 단순한 제작 설명문만 반환하지 않는다. 실제 이미지 제작 도구/파일 작성 도구가 없는 환경이라면 실제 만들지 않은 ZIP을 생성했다고 주장하지 않는다.
