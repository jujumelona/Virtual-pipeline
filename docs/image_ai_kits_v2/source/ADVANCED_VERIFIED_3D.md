# 3D 참조 원화 고급 기법 — 공식 규격과 제작 실무 구분

**중요:** 이미지 AI가 출력하는 것은 실제 렌더 이미지/디자인 참조 파일이다. VRM/GLB/FBX/실제 3D 메시·본·재질/스키닝/물리/애니메이션은 요구하지 않는다.

## 공식 VRM·Inochi 구분에서 그림에 반영할 부분

- VRM의 **Humanoid**는 실제 3D 신체의 골반·척추·팔·다리·머리 등의 본을 정의한다. 원화 AI는 이들을 모델링하지 않고 **A/T pose에서 관절 위치·몸통 비례가 식별되는 전신 참조 이미지**를 그린다. https://vrm.dev/en/vrm1/humanoid/
- **표정·시선**은 VRM에서 표준 기능을 갖는다. 그림 AI는 눈/눈썹/코/입/치아·혀와 필요한 표정 차이를 **상세 참고 그림**으로 제공하되 BlendShape/눈 추적 데이터를 생성하지 않는다. https://vrm.dev/en/vrm/vrm_features/
- 머리·귀걸이·옷자락·리본의 **SpringBone**은 후속 3D 동작 요소다. 그림 AI는 뿌리·매다는 지점·몸과의 간격·리본 연결과 두께를 **여러 각도에서 시각적으로 읽히게** 묘사한다. https://vrm.dev/en/vrm1/springbone/
- **실제 UV 텍스처 이미지**는 모델의 UV 지도가 필요하다. 이미지 AI에 임의의 그림만으로 정확한 UV 맵/스킨 텍스처가 완성됐다고 요구하지 않는다. 그 대신 재질/색상/무늬·경계 위치의 **디자인 가이드 이미지**를 그린다. https://docs.blender.org/manual/en/latest/modeling/meshes/uv/unwrapping/introduction.html

## 이미지 AI에게 요청할 구체적 고급 그림

1. **정면/후면/좌/우 각각 독립 생성**: 동일 캐릭터, 같은 키·몸 비례·헤어볼륨·의상 재질·소품 위치, 포즈 동일. 실제 다른 각도여야 하며 정면을 뒤집고 이름만 바꾸지 않는다.
2. **3면도/4면도 일관성**: 배경 단색·조명 균일·원근 왜곡 최소화. 정면·측면의 턱/귀/코 위치, 전후 머리 부피, 어깨·허리·골반·무릎 높이·팔/손 위치가 맞아야 한다.
3. **깊이 정보 보조**: 머리 층 구조·장식의 앞뒤 두께·후드 뒤쪽/의상 안감, 체인 길이와 부착점의 뒷모습까지 **별도로 직접 그린 참조 이미지**를 만든다.
4. **신체만**은 비선정적 불투명 기본 속옷 착용 — 이미지 AI가 나체를 생성하게 하지 않음. 속옷 교체용 그림 세트는 추가하지 않는다.
5. **헤어만 / 의상만 / 액세서리만**은 그 사용자가 지정한 한 자산에 대한 4면도와 필요한 디테일만. 장식 하나 요청 시 악세서리 세트 금지.
6. **눈·코·입 상세**는 전신 그림을 확대 잘라내지 않고 동일 인물·같은 치수/색상의 고해상도 개별 상세 그림으로 직접 생성한다.
7. 마지막에 완성되는 turnaround_sheet는 이미 직접 생성된 시점들을 **배열**하는 시트로서, 새로운 시점을 대신 생성한 것으로 간주하지 않는다.

## 비공식 제작 가이드 (공식 규격 아님)

- VTuber 3D 제작용 시트: **A-pose, 원근 최소, 정·후·측면 높이 정렬, 무늬·부착점·색상 가이드** 권장. https://virmii.com/blog/tutorial/how-to-make-vtuber-reference-sheet (2026-10-04 업데이트)
- Live2D 커뮤니티의 **비대칭 디테일 좌우 복사 위험/숨은 영역 준비** 의견은 3D 시점 그림의 디자인 일치에도 유효하지만 3D 규격의 공식 요구가 아님: https://www.reddit.com/r/Live2D/comments/v17npc

### 공식과의 경계

공식 VRM이 정의하는 것은 실제 3D 데이터/동작 규격이다. 이 ZIP의 다각도 PNG/파일명/확대 이미지 수는 **우리 이미지 제작 가이드**다. 고급 참조 그림을 제공했다고 3D 모델이 자동으로 만들어지거나 정확한 UV가 완성되는 것은 아니다.
