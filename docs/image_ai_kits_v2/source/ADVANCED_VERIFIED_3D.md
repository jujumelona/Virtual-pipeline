# 3D 참조 원화 고급 기법 — 공식 규격과 제작 실무 구분

**중요:** 이미지 AI가 출력하는 것은 실제 렌더 이미지/디자인 참조 파일이다. VRM/GLB/FBX/실제 3D 메시·본·재질/스키닝/물리/애니메이션은 요구하지 않는다.

## VRM의 후속 모델링 기능과 자산별 그림 범위 구분

- **신체 ZIP에서만:** VRM의 **Humanoid**는 후속 골반·척추·팔·다리·머리 본의 참고다. 이 ZIP에서는 본을 모델링하지 않고 신체 A/T pose에서 관절/몸통 비례가 식별되는 전신 참조 이미지만 그린다. https://vrm.dev/en/vrm1/humanoid/
- **신체 ZIP에서만:** 표정·시선 자료가 필요하면 눈·눈썹·코·입 및 실제 노출되는 입안의 상세 참고 원화를 그린다. 헤어/의상/단일 소품에는 얼굴 상세도를 요구하지 않는다. BlendShape/눈 추적 데이터 생성은 모든 ZIP에서 제외한다. https://vrm.dev/en/vrm/vrm_features/
- **해당 자산에 실제 있는 유연한 부분만:** SpringBone은 후속 3D 동작 요소다. 헤어는 가닥 뿌리, 의상은 실제 달린 리본/옷자락, 단일 소품은 그 물건의 체인/끈만 시점 그림으로 표현한다. 다른 종류 소품을 새로 생성하지 않는다. https://vrm.dev/en/vrm1/springbone/
- **실제 UV 텍스처 이미지**는 모델의 UV 지도가 필요하다. 이미지 AI에 임의의 그림만으로 정확한 UV 맵/스킨 텍스처가 완성됐다고 요구하지 않는다. 그 대신 재질/색상/무늬·경계 위치의 **디자인 가이드 이미지**를 그린다. https://docs.blender.org/manual/en/latest/modeling/meshes/uv/unwrapping/introduction.html

## 이미지 AI에게 요청할 구체적 고급 그림

1. **정면/후면/좌/우 각각 독립 생성**: **지금 요청된 자산 하나만** 같은 원점·배율·색·부착 관계로 네 방향에서 새로 그린다. 기존 신체·헤어·옷·소품은 필요한 경우 정렬 참고이며 신규 그림에 복사하지 않는다.
2. **8방향 턴어라운드 일관성**: 배경 단색·균일한 광원·작은 원근 왜곡. 신체면 턱/귀/코·관절 기준선, 헤어면 모근/볼륨, 의상이면 솔기·무늬, 소품이면 고정부·두께를 해당 ZIP에서만 정합한다.
3. **깊이 정보 보조**: 요청된 헤어의 가닥 뒷면, 옷에 실제 있는 후드/카라 안감, 요청된 소품의 체인/고정부 등 **그 한 자산에 속한 숨은 면만** 필요 시 추가 참조 원화로 제작한다.
4. **신체만**은 비선정적 불투명 스포츠 수영복 상의와 하이웨이스트 쇼츠 착용 — 이미지 AI가 나체를 생성하게 하지 않음. 속옷 교체용 그림 세트는 추가하지 않는다.
5. **헤어만 / 의상만 / 액세서리만**은 그 사용자가 지정한 한 자산에 대한 8방향 턴어라운드와 필요한 디테일만. 장식 하나 요청 시 악세서리 세트 금지.
6. **신체 ZIP에서만:** 필요한 눈·코·입 상세 원화는 기준 신체와 동일한 디자인으로 고해상도 별도 작화한다. 헤어/의상/액세서리 ZIP에서는 생성하지 않는다.
7. 마지막에 완성되는 turnaround_sheet는 이미 직접 생성된 시점들을 **배열**하는 시트로서, 새로운 시점을 대신 생성한 것으로 간주하지 않는다.

## 비공식 제작 가이드 (공식 규격 아님)

- VTuber 3D 제작용 시트: **A-pose, 원근 최소, 정·후·측면 높이 정렬, 무늬·부착점·색상 가이드** 권장. https://virmii.com/blog/tutorial/how-to-make-vtuber-reference-sheet (2026-10-04 업데이트)
- Live2D 커뮤니티의 **비대칭 디테일 좌우 복사 위험/숨은 영역 준비** 의견은 3D 시점 그림의 디자인 일치에도 유효하지만 3D 규격의 공식 요구가 아님: https://www.reddit.com/r/Live2D/comments/v17npc

### 공식과의 경계

공식 VRM이 정의하는 것은 실제 3D 데이터/동작 규격이다. 이 ZIP의 다각도 PNG/파일명/확대 이미지 수는 **우리 이미지 제작 가이드**다. 고급 참조 그림을 제공했다고 3D 모델이 자동으로 만들어지거나 정확한 UV가 완성되는 것은 아니다.
