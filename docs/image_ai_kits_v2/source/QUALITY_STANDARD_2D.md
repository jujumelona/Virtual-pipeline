# 반드시 충족할 2D 상업용 원화 수준 — 이미지 AI용

이 문서는 **PNG 파일명이나 분리 개수보다 실제 작화 품질을 우선**하기 위한 지침이다. 참고 그림의 정체성·스타일이 사용자에게 주어졌으면 해당 스타일을 최우선으로 유지한다. 구체 스타일 정보가 없다면 **정교하게 그려진 현대적인 애니메이션/Vtuber 캐릭터 원화**를 기본값으로 한다. 공식 샘플 캐릭터의 외형 자체를 베끼지 않는다.

## 필수 작화 품질

- **형태:** 인체 비례와 목·어깨·상완·팔꿈치·손목·손·얼굴의 구조가 자연스러워야 한다. 이음매가 소시지·로봇 관절처럼 구분되는 불연속 도형이 되어서는 안 된다. 스타일화된 체형이어도 의도된 디자인으로 일관되어야 한다.
- **선화:** 균일한 두께의 단순 도형 외곽선 대신, 부위에 따라 강약이 있는 깔끔하고 섬세한 선화. 눈꼬리, 머리카락, 피부·손가락 윤곽과 옷 솔기에 필요한 디테일을 실제로 그린다.
- **채색·질감:** 눈·피부·소재의 자연스러운 음영·색 변화, 가벼운 반사광과 볼륨. 단순 단색 도형·기계적인 그라데이션·아이콘/플랫 벡터 템플릿 스타일로 완성품을 대신하지 않는다. 사용자 참조 스타일이 평면 채색을 요구하면 그 스타일을 따르되 인체·선화 완성도는 유지한다.
- **눈·입:** 얼굴에 실제로 어울리는 눈매·홍채 세부 무늬·하이라이트·눈꺼풀, 자연스러운 코/입 위치와 표정. 파일 수를 늘리려고 빈 사각형 하이라이트나 쓸모없는 조각을 만드는 것은 금지한다.
- **신체의 기본 옷차림:** 나체가 아닌 **불투명·비선정적 기본 속옷**을 착용한 베이스. 허벅지까지 내려오는 회색 긴 셔츠·튜닉처럼 신체 구조를 감추는 임의의 겉옷은 **속옷 조건의 대체품이 아니다**. 피부를 그리는 작업과 기본 속옷 디자인을 안전하고 자연스럽게 조화시킨다. 별도 속옷 교체 레이어는 만들지 않는다.
- **고급 분리:** 품질 좋은 원화가 바탕이다. 정해진 PNG 총량을 채우기 위해 단순 원·타원·입술 호·직사각형 등만 만든 뒤 '35파츠 완성'이라 하지 않는다. 먼저 각 부위의 완성도를 확보한 뒤 다른 움직임/가림이 필요한 파츠를 처음부터 따로 그린다.
- **가려진 원화:** 앞머리 아래 피부, 눈동자 뒤 흰자, 입술 밑 입안, 귀 뒤, 목·팔꿈치·손목·옷 아래의 가려진 영역도 **동일한 그림 수준으로** 제대로 채운다.

## 이미지 생성 도구 우선

**캐릭터 그림의 픽셀은 실제 이미지 생성/편집 기능으로 제작**한다. 도형·베지어·SVG·Pillow/Matplotlib로 간단한 캐릭터를 그리는 **프로그래밍식 삽화**를 고품질 원화로 제출하지 않는다. 코드 도구는 PNG 분리 저장·알파 확인·레이어 정렬·ZIP 압축·비교 합성 등에만 보조 사용 가능하다. 실제 그림 생성 도구가 없거나 독립 파츠 원화를 충분히 그릴 수 없다면 **제작 기능이 없음을 밝히고 가짜 최종 ZIP을 만들지 않는다.**

## 첫 이미지부터 퀄리티 확보

1. 전체 제작에 앞서 캐릭터 스타일·비율·색상·눈매·선화·채색 품질의 **작화 기준**을 잡는다. 제공된 이미지가 있으면 동일 캐릭터·스타일을 유지한다. 없으면 세밀하고 세련된 애니메이션 원화로 제작한다.
2. 완성 정면 이미지를 자동 분리하기 위한 마스터로 생성하지 않는다. 배치용 러프/가이드와 **독립 파츠를 실제 고품질로 그린 이미지**를 처음부터 준비한다.
3. **처음부터 한 부위씩 제대로 그리며** 부품을 같은 스타일·광원·색상·원점에 맞춘다. 각 PNG가 서로 다른 단색 도형이나 서로 다른 AI 스타일처럼 보이면 그 파츠부터 다시 그린다.
4. 실제 파츠들을 합성한 중립 미리보기를 사용자 스타일 기준과 비교한다. **얼굴이 단순한 벡터 마네킹, 지나치게 큰 팔/작은 손, 상의가 몸을 덮는 긴 천, 도형처럼 분절된 관절**이 나오면 정상으로 승인하지 않는다. 해당 신체 파츠와 원화를 다시 그려서 합성·재점검한다.

## 공식 예제: 단순 URL 존재 ≠ 시각적 참고 완료

- [Live2D 공식 일러스트 가공 튜토리얼](https://docs.live2d.com/en/cubism-editor-tutorials/psd/) — 분리 원칙·그림 보완과 **모모세 히요리 원본 PSD 내려받기** 안내.
- [일러스트 가공 공식 샘플 ZIP 다운로드](https://cubism.live2d.com/editor-tutorial/momose1/momose_tutorial01.zip) — 공식 원본 ZIP; 참고 이용 조건 확인. 직접 열고 원화 품질·색·선·레이어 구조를 참조할 수 있을 때만 사용. 이 지시서 ZIP 안에 그 PSD가 동봉된 것은 아님.
- [Live2D 공식 템플릿 튜토리얼](https://docs.live2d.com/en/cubism-editor-tutorials/template/) — 가이드 선화 후 부위별 선화/채색 그리기.
- [Live2D 공식 샘플 모델 모음](https://www.live2d.com/en/learn/sample/) — 다양한 실제 캐릭터 원화 표현·레이어 예제. **권리 확인 없이 공식 샘플 파일을 재배포하거나 외형을 복제하지 말 것.**
- [Live2D 공식 소재 분리](https://docs.live2d.com/en/cubism-editor-manual/divide-the-material/) — 움직임용 부위 분리와 뒤쪽 원화 보완.

**사이트를 실제 열거나 파일을 읽지 못했으면 읽었다고 주장하지 않는다.** 링크는 참고 경로이지 생성 AI가 샘플의 내용을 자동으로 읽었다는 증명이 아니다. 링크 접근 불가 시에도 이 문서의 **원화 품질 요구를 실제 그림에 적용**한다.

## 최종 납품 전 미술적 판단

파츠 수·CRC·확장자·좌표가 맞아도 **그림이 어색하고 조악하면 품질 미달**이다. 재생성·수정 후 독립 이미지와 합성본을 다시 보면서 **사용자가 요구한 작화 수준을 충족**할 때만 최종 ZIP을 제공한다. 리깅·PSD/모션/회전 검사·형식적 품질 인증서는 요구하지 않는다.
