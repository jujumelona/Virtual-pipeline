# 액세서리만 — 사용자가 지정한 바로 그 물건만

'머리장식'이라고 주문하면 **머리장식**, '안경'이면 **안경**, '귀걸이'면 **귀걸이**만 생성한다. **액세서리 세트 자동 생성은 금지**한다. 인접한 헤어·의상·얼굴을 별도 자산으로 만들지 않는다.

하나의 단단한 머리핀/안경테는 **한 파츠 PNG**만으로 충분할 수 있다. 머리 장식 리본·체인·흔들리는 끈·보석처럼 **그 물건 자체에만** 서로 다른 움직임/깊이가 있을 때 해당 부분을 처음부터 분리 원화로 만든다.

- 기본 이름: accessory_<requested_type>_main.png
- 필요한 경우에만: accessory_<requested_type>_ribbon_L.png / _ribbon_R.png / _chain_01.png / _charm.png
- 실제 부착 위치는 사용자 기존 머리/귀/목/손목 등 기준 이미지에 맞춤. **기준 캐릭터를 다시 생성하지 않는다.**
- 미리보기에서만 사용자 기준 신체/헤어 위에 해당 장식만 합성한다.

이름의 requested_type은 사용자 말에 맞게 지정하되, ZIP에 **사용자가 고르지 않은 종류를 멋대로 추가하지 않는다**.
