# 의상만 — 완성 원화 우선, 요청한 옷의 실제 움직일 파츠만 분리·보완

옷 종류를 묻거나 사용자의 설명(원피스/재킷/셔츠/교복/드레스 등)에 따른다. **옷 한 벌의 실제 구조만** 그린다. 몸·헤어·별도 귀걸이/안경 세트는 생성하지 않는다.

옷의 고정 문양, 자수, 인쇄는 다른 움직임이 없으면 옷감 파츠에 남긴다. 프릴·리본/카디건 안쪽처럼 독립 움직임/깊이가 있으면 **완성된 의상 원화에서 필요한 부분만 분리하고 가려진 옷감을 추가 작화한다**. 기준 몸의 크기·원점과 맞추며 **신체 픽셀을 의상 파츠에 섞지 않는다**.

### 자산 전용 고급 의상
- 요청한 의상 하나의 옷깃·양 소매·몸판과 실제 존재하는 옷 안감/리본/문양만 제작한다.
- 옷깃 아래·어깨/소매 이음·겹친 천의 뒷면을 underpaint하고 관절/목 변화 후 배경 틈을 막는다.
- 원단에 따라 주름·두께·반사광을 다르게 표현하고 정적인 자수·솔기는 별도 레이어를 강제하지 않는다.
- 상반신에 하체를, 전신에 없는 바지·신발을 자동 생성하지 않는다. 기준 신체/헤어/귀걸이 픽셀 복제 금지.

### [2026-10-13 정량 추천·측면/목 원화 소유권 outfit]
[카라/목 접합] 턱 아래 피부나 귀 뒤 목을 새로 그리지 말고, 그 피부가 움직일 때 노출될 **카라 안쪽 천·뒤칼라·소매/어깨 연결 뒤쪽 옷감**만 연장한다. 진짜 목회전/옆얼굴 참조와 기준 몸체를 합성했을 때 목깃 아래로 배경색 구멍이 생기지 않아야 한다. 좌우 카라의 앞뒤 순서와 원단 두께·주름을 실제 요청 의상에 맞춘다.

[의상 측면/목 접합 QA] 기준 신체(참조)의 목·귀 뒤 피부와 요청 의상의 옷깃 사이 틈/목 관통/카라 잘림이 있는가? 의상 PNG에는 피부·얼굴·헤어가 없어야 한다. 디자인에 없는 후드·넥타이·하의·목걸이를 임의 생성하지 않는다.

[Live2D 공식 참고] https://docs.live2d.com/ko/cubism-editor-tutorials/psd/ — 카라·가디건의 움직일 부분은 필요에 따라 분리; 목 자체는 신체 원화. [아티스트 작업 팁] 얼굴과 목 3/4 회전을 참조해 카라 안쪽·뒤칼라와 좌우 목깃에 가려진 옷감을 추가 작화한다.
