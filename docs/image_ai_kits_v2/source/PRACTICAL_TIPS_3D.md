# 3D 디자인 참조 이미지 제작 팁 — 비공식 제작 실무를 실제 이미지에 적용

**이미지 AI가 실행할 작업만 다룬다.** 아래는 비공식 아티스트 작업 관례·실무 팁이며 VRM/Blender 공식 의무사항이 아니다.

## 1. 그림 4장의 '같은 캐릭터' 유지

- **한 기준 색상표·비율표와 디자인**을 정한 뒤 네 각도 모두에 같은 방식으로 적용한다. 성격이 달라 보이는 얼굴/귀/코·비대칭 무늬·리본 위치를 바꾸지 않는다.
- 신체·의상은 처음부터 **같은 A-pose 또는 T-pose**, 발 위치·양손 높이·어깨 넓이·골반 높이를 반복해서 비교한다.
- 정면/후면/측면의 **기준 수평선(눈·어깨·손목·허리·무릎·바닥)**을 사용해 길이 불일치를 시각적으로 줄인다.
- 일관된 관찰각도와 비슷한 확대율/조명, 최소 원근 과장으로 모양을 쉽게 비교할 수 있게 한다.

## 2. 다른 방향의 숨은 구조를 '추정 크롭'하지 않는다

- 정면 그림 좌우 미러를 측면이라고 제출하지 않고, **측면은 깊이·두께가 읽히는 그림으로 새로 생성**한다.
- 머리카락 뒤통수 층·옷깃/후드 뒤·옷감 겹침/안감·장식 뒷면·실제 부착 위치를 각각 해당 시점에서 그린다.
- 표정·눈·코·입·손·발은 모델용 디테일 참고가 필요할 때 **확대 크롭이 아닌 별도 선명한 그림**으로 그린다.
- UV 전개나 표면 텍스처 완성은 실제 3D 메시의 UV가 필요하므로 **그림만으로 구현됐다고 주장하지 않는다**.

## 3. 사용자 지정 자산 범위 보존

- 신체: **나체가 아닌 불투명 기본 속옷을 입은** 전신 그림. 얼굴·눈·코·입·손발은 신체 안의 상세 참고.
- 헤어: 사용자 요청 헤어스타일 한 종류에만 집중. 뿌리·옆머리·뒷머리 등 실제 구조를 네 방향에서 보여줌.
- 의상: 요청한 옷의 앞/뒤/솔기/두께/주름과 실제 있는 장식만.
- 액세서리: '머리장식'이라고 했으면 그 장식 한 종류의 정면·측면·후면과 부착점만. 액세서리 세트 만들지 않음.

## 4. 비교 미리보기·반복 수정

- 각 방향 이미지를 실제로 생성한 **다음에** 턴어라운드 시트에 같은 키/정렬선으로 배열한다.
- **같은 키·체형·색·디테일·부착 위치**를 비교하고 차이가 있으면 해당 방향 그림을 다시 생성해서 교체한다.
- `07_REVIEW_BEFORE_FINAL_ZIP.md`의 기준이 모두 해당하는 상태에서 충족될 때만 결과 ZIP을 제공한다. 작업이 불가능한 경우 가짜 완성 파일을 내놓지 않는다.
