# 3D 참조 이미지 AI 결과물 — 다각도 그림 반복 점검 후 최종 ZIP 납품

**필수 제작 절차**이며 3D 모델러/애니메이터의 후속 작업을 이미지 AI에 요구하지 않는다. 이미지 AI는 **정면·후면·좌측·우측 실제 이미지와 필요한 상세 그림**만 만들고 확인한다.

1. 사용자가 요청한 자산 유형을 분명히 한다: 속옷 착용 신체 / 사용자 지정 헤어 / 지정한 의상 / 사용자 지정 액세서리 **한 종류**. 다른 자산을 자동 포함하지 않는다.
2. 시점별 그림을 **각각 새로 그려** `views/`에 저장한다. 정면을 좌우로 뒤집거나 이름만 바꾸어 측면·후면으로 제출하지 않는다. 눈·코·입·손 등 필요한 `details/` 확대 그림도 실제 별도로 그린다.
3. 네 방향 이미지를 **같은 높이와 기준선으로 나란히 배열한 미리보기**를 만들고, 아래 사항을 실제 이미지에서 확인한다.
4. 불일치나 누락이 있으면 **해당 방향 또는 세부 부위를 다시 그리거나 수정**한다. 4방향 모두와 미리보기를 다시 대조한다. 문제가 남으면 이 과정을 **반복**한다.
5. PNG·턴어라운드 시트·결과 ZIP이 모두 실제 생성됐는지, 필요한 부위·파일명이 맞는지 확인한다. 가능할 때 파일을 다시 열어 무결성을 확인한다.
6. **적용 가능한 모든 이미지 제작 요구 충족이 확인됐을 때만 최종 결과 ZIP을 납품**한다. 구현할 수 없는 파일 작업이나 남은 불일치가 있다면 미완료 이유를 알리고 만들어지지 않은 ZIP을 최종품이라고 주장하지 않는다.

## 다각도 이미지 체크리스트

- [ ] **정확한 선택 범위:** 신체·헤어·의상·지정 액세서리 하나 중 해당 종류만 생성했다.
- [ ] **같은 디자인:** 앞·뒤·좌·우 모두 같은 물건/캐릭터의 색·형태·무늬·장신구 위치이며 좌우 비대칭이 일관된다.
- [ ] **정합:** 신체/의상은 같은 A/T 포즈, 얼굴/어깨/가슴/허리/골반/무릎/발끝 및 팔 위치·길이가 시점마다 합리적으로 일치한다.
- [ ] **기하적 읽힘:** 실제 뒷면과 좌우 측면에서 두상·헤어 볼륨·코/귀·옷깃/안감·옷의 두께·소품 뒤쪽 형상·고정점이 읽힌다.
- [ ] **이미지 관점:** 원근 과장이 적고 배경·조명·비율/스케일이 비교 가능한 4방향 그림이다. 회전 그림의 모양만 다른 인물이 아니다.
- [ ] **세부 원화:** 사용자가 실제 요청한 신체의 눈·눈썹·코·입·귀·손발, 또는 헤어뿌리/의복 솔기/소품 내부 구조가 전신 그림의 단순 확대 크롭이 아닌 선명한 추가 그림으로 제공됐다.
- [ ] **노출 방지:** 신체일 때 불투명하고 비선정적인 기본 속옷 착용, 별도 속옷 교체 자산 요구 없음.
- [ ] **미리보기/파일:** `views/*.png`의 실제 이미지 4장을 마지막에 나란히 배열한 `previews/turnaround_sheet.png`이며, `04_OUTPUT_FILES.md`에서 이 작업에 실제 필요한 PNG가 결과 ZIP에 존재한다.
- [ ] **후속 작업 구분:** UV, 메시, 본, 스프링본, VRM/FBX/GLB, 모델 구동·움직임/회전 테스트가 이미 됐다는 허위 주장 없음.

문제가 남았을 때 합격 보고서로 덮어쓰지 않는다. 재작업 가능한 이미지 문제를 고치고 다시 확인한다. **임의 점수/고정 루프 횟수/형식적인 자동 품질 인증 문서는 요구하지 않는다.**
