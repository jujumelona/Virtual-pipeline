# 3D 전용 이미지 참조 규칙

3D 모드에서 이미지 AI가 내놓는 것은 **3D 모델링을 위한 일관된 다각도 그림 자료**이다. 단일 정면 이미지를 늘리거나 좌우 측면이라고 이름만 바꿔 제출하지 않는다.

- views/*_front.png, *_back.png, *_left.png, *_right.png 형태로 실제 서로 다른 시점에서 같은 물체를 일관되게 그린다. 가능하면 원근이 적은 정투영/정면 관찰 구도.
- 신체/의상은 같은 A pose 또는 T pose, 실제 관절 길이·치수·소매 길이·어깨높이 일치.
- 신체 안에서 눈·코·입·손·발 등 세부 그림을 전신 그림과 **별도 생성**하여 details/에 넣는다. 표정이 필요하면 입 열림·닫힘과 눈 구조를 개별 이미지로 제공할 수 있다.
- 사용자 요청한 헤어/의상/장식 모드는 그 종류만 다각도로 그린다. 다른 물건을 세트로 추가하지 않는다.
- previews/turnaround_sheet.png는 **실제 생성된 시점 그림을 마지막에 단순히 배열**한 것.
- image AI에게 메쉬/VRM/본/리깅/실시간 렌더 테스트를 요구하지 않는다.
