# 고품질 애니풍 그림 예시 — 원화 AI에 보여줄 실제 공식 이미지 링크

**중요:** 이 ZIP에는 저작권/라이선스가 있는 Live2D 공식 캐릭터 원화 이미지 파일을 **복사하여 포함하지 않았다**. 대신 아래 **공식 사이트의 실제 샘플 이미지 직접 URL과 미리보기**를 삽입했다. Markdown의 이미지 미리보기를 지원하면 예시가 표시된다. URL에 접근할 수 없는 AI는 예시를 보았다고 주장하면 안 된다. 사용자가 별도 스타일 참조를 줬다면 그 스타일을 우선한다.

## 예시 A — Live2D 공식 Tsumiki 애니풍 캐릭터
![Live2D official Tsumiki anime VTuber reference](https://www.live2d.com/wp-content/themes/cubism_new/assets/img/sample/sample-img-tsumiki.png)

- 직접 이미지 URL: https://www.live2d.com/wp-content/themes/cubism_new/assets/img/sample/sample-img-tsumiki.png
- [공식 샘플 데이터 페이지](https://www.live2d.com/en/learn/sample/)
- 참고 항목: 큰 애니 눈매, 검정에 가까운 굵고 선명한 주요 윤곽선, 애니식 옷 주름·선화, 얼굴·신체 비례. 캐릭터 디자인이나 복장 자체를 베끼지 않는다.

## 예시 C — 실제로 파츠별 원화를 그리는 공식 설명

- [공식 Live2D 그림 제작 템플릿](https://docs.live2d.com/en/cubism-editor-tutorials/template/): **가이드 스케치 → 각 파츠별 선화·채색**과 눈꺼풀/입 피부 채움, 숨겨진 영역의 추가 원화.
- [공식 그림 가공 튜토리얼/샘플 PSD](https://docs.live2d.com/en/cubism-editor-tutorials/psd/): 피부·눈·머리·입·신체 파츠 원화 분리의 실제 사례.
- [Live2D Niziiro Mao](https://www.live2d.com/en/learn/sample/niziiro-mao/): 애니풍 버튜버 전면형 모델의 공식 캐릭터.
- [공식 라이선스](https://www.live2d.com/eula/live2d-free-material-license-agreement_en.html): 공식 샘플 이미지 자체를 이 지시서에 재배포하지 않는 이유.

## 눈으로 비교할 사항

- 진한 외곽선은 바깥과 눈 윗속눈썹에서 또렷하지만 **고정 굵기의 검은 테두리만으로 이루어진 벡터 인형이 아니다**.
- 부위 안쪽 선화와 피부·머리 톤은 주변 색을 따라 변하고, 얇은 코·입 라인/눈꺼풀/볼의 미묘한 음영이 있다.
- 신체·헤어·의상·장신구의 모든 독립 파츠가 **한 명의 애니메이션 일러스트레이터가 그린 것처럼** 같은 채색과 선화를 유지한다.
- **실제 이미지 접근 없이 텍스트 링크만 읽었을 때는 예시를 직접 보았다고 보고하지 않는다.** 시각 기준을 확인할 수 없다면 `09_VISUAL_ART_QUALITY.md`·`10_ANIME_STYLE.md`의 그림 요건을 충실히 따른다.
