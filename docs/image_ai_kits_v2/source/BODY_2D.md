# 신체만 — 6등신 완전 애니풍 VTuber 원화 → 필수 파츠 추출 (Live2D/Inochi2D)


## 우선 적용: 애니풍 버추얼 신체 베이스 (실패한 반실사 사례 수정)

**이 모델은 사실적인 알몸 인체를 재현하는 프로젝트가 아니다.** 머리/의상/액세서리를 나중에 끼울 수 있는 *애니풍 VTuber 마네킹 베이스*다. 신체 부위 자체의 구분과 작동 가능한 관절은 필요하지만, 실제 사람 피부·근육의 해부학적 묘사는 불필요하고 금지한다. 아래는 기본 미술 방향이며 사용자가 특정 애니풍 디자인을 지정하면 그 고유한 스타일에 맞춘다.

- **전신 디자인은 정확히 6등신:** 두상 **정수리~턱**의 높이를 1로 보고 **정수리~발바닥까지 정확히 머리 6개 높이**를 기준으로 설계한다. 풀바디의 간단한 스케치는 **머리 1 : 상체 2 : 하체 3** 영역으로 시작하고, 캐릭터 성별·체형·자세에 따라 어깨/골반/팔 길이는 스타일에 맞게 다듬되 **최종 머리:전신 높이 1:6은 유지**한다. 머리카락 볼륨/장식은 두상 측정에서 제외한다. 7~8등신 실사 패션 모델, 작은 머리와 긴 몸통, 과도한 흉곽·다리 길이 금지. **상반신만 생성할 때는 6등신 전신의 상대 두상·어깨 비례만 참고하고, 전신 그림을 새로 그리지 않은 채 상반신 원화를 처음부터 제작**하며, 화면 크롭 때문에 머리·목·어깨가 실사 비율로 축소되지 않도록 한다. 이 프로젝트의 6등신을 다른 임의 등신 범위로 자동 변경하지 않는다.
- **눈은 크고 시선을 지배하는 애니풍:** 얼굴 크기 대비 두 눈의 가로폭과 세로 높이를 **실사보다 뚜렷하게 크게**, 홍채·동공을 눈 안에서 충분히 크게 잡는다. 매력적인 윗속눈썹·눈꼬리·큰 하이라이트·눈 색 그라데이션/셀 하이라이트를 중심으로 표정을 설계한다. 작은 실사 눈, 작은 홍채, 실사 눈꺼풀·안와 음영은 금지. **눈 폭을 작은 실사 비율이나 임의의 고정 퍼센트로 제한하지 않는다.** 숫자만으로 얼굴 그림체를 결정하지 않고, 공식 애니 Live2D 예제와 실제 캐릭터 시각 비교로 크고 또렷하게 조정한다.
- **얼굴·입·코 비례:** 얼굴의 상반부에 큰 눈이 우선 읽히도록 하고, 코는 작고 단순한 선/점/작은 셀 음영, 중립 입은 **두 눈보다 훨씬 작고 얇게** 표현한다. 실사 콧대·복잡한 콧구멍·도톰한 입술·인중/입술 주름 및 사실적인 구강 돌출 금지. 눈과 입을 함께 크고 실사처럼 그리지 않는다.
- **귀:** 귀는 애니풍으로 단순화된 외곽·1~2단계 안쪽 음영까지만 그린다. 복잡한 사람 귀 연골, 실사 귓구멍, 갈라지는 귓바퀴·그라데이션 음영은 넣지 않는다. 캐릭터의 큰 눈·단순한 코와 같은 선화·셀 셰이딩 수준으로 맞춘다.
- **입의 유일성:** 중립 합성에서 눈에 보이는 **입은 정확히 하나**다. `mouth_close.png`(다문 상태)와 `mouth_open.png`(최대로 벌린 입안 전체)는 서로 대체되는 두 상태다. 입 위·아래 라인을 독립으로 그린 경우, *같은 입 하나의 상/하 구성요소*이지 별도의 두 번째 입이 아니다. 입안·치아·혀는 열린 입의 내부이며 닫힐 때 보이지 않는다. 같은 입 모양을 얼굴 베이스에 중복으로 그리지 않는다.
- **목이 안 잘리는 원화:** `neck.png`의 상단 피부는 턱/얼굴 아래 깊이까지, 하단 피부는 쇄골·몸통의 겹침 안쪽까지 **숨겨진 부분을 실제 픽셀로 길게** 확장한다. 턱 아래 피부·귀 뒤·목 측면도 회전 시 드러날 폭을 그린다. 단순 경계 맞춤이나 알파 채우기만으로 해결했다고 하지 않는다. 얼굴·목·몸통의 피부 명암도 경계에서 일치시킨다.
- **옆모습은 별도 원화가 필요:** 정면 PNG를 옆으로 잡아당긴 변형은 측면 얼굴이 아니다. 머리 옆 윤곽, 코 돌출, 귀 앞/뒤 위치, 눈의 가림, 턱·목의 실제 측면 실루엣을 맞춘 **좌/우 3/4 원화와 좌/우 옆모습 참조**를 별도로 그린다. 머리·귀·목 파츠에 가려졌다가 나타나는 피부/윤곽도 준비한다. 이 참조는 Cubism에서 추가 키폼·아트메시 보정을 하는 데 쓰이며, 단순 이미지 존재만으로 자동 네이티브 측면 리깅이 완성되었다고 주장하지 않는다.
- **단일한 스타일 계약:** 검은색에 가까운 두께 가변 라인(끝이 얇아지는 테이퍼), 일관된 2~3단계 셀 셰이딩, 캐릭터 특유의 눈/귀/턱 비례. 사진 같은 피부 모공·복잡한 입술/귀 내부·근육 볼륨·물렁한 몸 그림자 금지.

### 결과 이미지에 반드시 나타나야 할 증거 (원화 AI가 검사 가능한 부분)

`reference_views/head_front.png`, `reference_views/head_three_quarter_L.png`, `reference_views/head_three_quarter_R.png`, `reference_views/head_profile_L.png`, `reference_views/head_profile_R.png`: **서로 다른 시점의 실제 그림**. 이름만 다르게 저장한 정면 복사나 단순 미러링은 불합격. 옆모습은 코·턱·귀의 가림 순서가 정면과 실제 달라야 한다. 측면 그림이 본 PSD에 자동으로 매핑되는 것은 아니다.

`previews/mouth_closed.png`와 `previews/mouth_open.png`: 실제 입 파츠의 표시 상태를 바꿔 합성한 두 미리보기. 닫힌 입에서는 열린 입안이 보이면 안 되고, 열린 입에서는 닫힌 입 선이 두 번째 입처럼 겹치면 안 된다. 모든 눈/입 파츠의 표시는 반드시 의도된 깊이·상태에 맞춰 관리한다.

`previews/neck_overlap.png`: 목을 가리던 턱/몸통을 일부 숨겼을 때 목 피부가 **실제로 연장되어 그려져 있음**을 보여주는 참고 미리보기. 그림을 숨겨도 목이 투명하게 잘리면 그 파츠부터 보완한다.

이미지 AI가 직접 할 일은 위와 같은 실제 그림·PNG·합성·ZIP 검토까지다. 3D 회전 시뮬레이션, Cubism 키폼 제작, MOC3 품질 인증까지 이미지 AI에게 떠넘기지 않는다. **생성 원화 품질을 사람이 보아 애니풍 마네킹이 아니거나 입·귀·목·옆모습이 어긋나면 ZIP 납품 전에 원화부터 고친다.**


**신체 범위:** 얼굴·눈·눈썹·코·입·귀·목·몸통·양팔·손, 전신이면 골반·양다리·발. 사용자에게 헤어/의상/액세서리를 함께 제공하는 세트가 아니다.

**중립 BODY 프록시:** 얼굴과 표정은 애니풍 원화로 작업하고, 몸통은 불투명 회색/베이지색 단색 도형 프록시로 후처리해 제작한다. 속옷·옷자락·가슴·겨드랑이·쇄골의 사실적 윤곽과 눌림을 그리지 않는다. 옷·헤어·장식은 각 독립 ZIP에서만 만든다.

### 실제 생성 순서 — 최신 마스터 우선, 서로 모순되는 지침 금지

1. **전신 신체 ZIP에서만** 정수리~턱 H와 전신 6H의 비례 스케치를 만든다. 일반 상반신은 이미 정해진 6등신 스타일의 두상·어깨 인상만 참고하며, **바스트업은 전신 스케치 없이 얼굴을 크게 그리는 근접 원화부터** 제작한다. 큰 애니 눈·홍채·작은 코·입은 세 구도 모두에서 원본 디자인대로 표현한다.
3. **해당 완성 원화에 보이는 실제 구성 요소**를 움직임·깊이·표정에 따라 파츠로 분리하고, 그림이 없어서 움직임에 필요한 가려진 눈·입·목·관절 영역은 독립적으로 **추가 작화한다**. 손상 없이 분리되지 않는 부위는 다시 그린다.
4. 양눈 흰자·커다란 홍채·속눈썹·눈꺼풀·눈썹, 작은 단일 입의 닫힘/열림, 귀/목/팔 관절 등 **실제로 독립 움직이는 부위만 충분히 세밀하게** 처리한다. 파츠 수는 27개 등 숫자로 제한하지 않는다.
5. 별도 **실제 좌우 3/4/옆모습**, 입 열림/닫힘과 목 숨은 피부 프리뷰를 생성한다. 파츠 합성 중 실사 비율로 틀어지거나 두 입/끊긴 목이 생기면 원화부터 고친다.
6. 실제 파츠를 뒤→앞 순서로 합성해 마스터와의 시각적 일치·눈의 크기·6등신·스타일 일관성을 확인한다. 그림/PNG/ZIP 제작은 여기까지이며 Cubism 리깅/MOC3 완성은 별도 실제 작업이다.

**원화 먼저 → 원화에서 파츠 추출 → 숨은 부위 추가 작화**가 최상위 제작 순서다. 오래된 "완성 그림부터 시작하지 말라"는 문구를 우선 적용하지 않는다.

### 자산 전용 고급 얼굴/비율 작화
- **프로젝트의 전신 신체 6H**는 Live2D 공식 수치가 아니다. 상반신은 그 인상을 보존한 상태로 실제 상반신만 그린다.
- 큰 홍채·선명한 윗속눈썹·작은 코와 입·단순한 귀·부드러운 셀 채색을 하나의 애니풍으로 통일한다. 고정 눈폭 퍼센트·복잡한 실사 인체 해부 묘사를 강제하지 않는다.
- 홍채 뒤 흰자·입안·눈꺼풀 아래 피부·귀 뒤·턱 뒤 목·필요한 관절 아래의 피부를 동질 원화로 보완한다. 입 열림/닫힘이 동시에 두 개 보이지 않게 처리한다.
- 3/4·측면 자료가 필요하면 먼 눈의 원근·코/턱 돌출·귀 위치가 바뀐 별도 참조 원화를 그린다. Cubism 키폼은 별도 작업.
