# 2D 이미지 AI 결과물 — 생성 → 시각 점검 → 문제 파츠 수정 → 재점검 → 최종 ZIP

**필수 작업 절차.** 이 문서는 이미지 AI가 실제로 수행할 수 있는 **그림·파일 품질 점검**만 요구한다. Live2D/Inochi2D 리깅, 구동, 물리, 회전 각도·모션 테스트, PSD/MOC3 제작, 미실행 검사 합격 인증은 요구하지 않는다.

## 반복 작업

1. `00_READ_FIRST.md`의 상위 모드/자산과 사용자의 디자인 요구를 읽어 해당 자산의 **실제 필요한 파츠**를 결정한다. 임의로 파츠 개수를 고정하지 않는다.
2. **완성된 기준 원화부터 먼저 제작한 뒤**, 필요한 파츠를 실제 독립 원화로 분리·보완한다. 완성본에 단순 마스크만 씌워 독립 원화라고 주장하지 않는다.
3. 실제 PNG를 동일 기준 캔버스/원점에 정렬하고, 그 PNG만 사용해 **합성 미리보기**를 만든다. 투명 영역과 불투명 영역이 의도대로 되었는지 확인한다.
4. 아래 항목을 **이미지 자체와 파일을 열어서 확인할 수 있는 범위에서 하나씩 확인**한다. 문제를 찾으면 그 파츠의 원화를 **다시 생성하거나 보완**하고, 같은 이름의 해당 PNG·합성 미리보기를 갱신한다.
5. 수정에 따라 생긴 새로운 문제까지 다시 점검한다. **적용 가능한 그림/파일 요건을 모두 충족할 때까지 이 3→4→5 과정을 반복**한다. 문제가 남은 PNG들을 임의로 '최종 완성품'으로 선언하지 않는다.
6. 마지막으로 `04_OUTPUT_FILES.md`를 대조해 모든 **실제 필요한** 파츠·`layer_order.txt`·미리보기를 포함한 결과 ZIP을 작성한다. ZIP 내부 PNG를 실제로 다시 열 수 있으면 열어서 파일 누락/오류를 확인한다. 파일 작성·열기 기능이 없다면 실행했다고 주장하지 않는다.
7. **모든 해당 항목 충족이 확인된 경우에만 최종 결과 ZIP을 제공**한다. 도구로 구현·확인할 수 없거나 남은 결함이 있으면 결과를 완료로 표시하거나 빈/대체 ZIP을 최종으로 제공하지 말고, 미완료 원인과 남은 파츠만 간단히 알린다.

## 공통 이미지·파일 점검 항목

- [ ] **대상 정확성:** 선택한 모드가 상반신/전신인지, 작업 종류가 신체/헤어/의상/특정 액세서리인지 지켰다. 없는 하의·불필요한 장식·액세서리 세트를 임의 추가하지 않았다.
- [ ] **캐릭터 일관성:** 기준 이미지가 제공됐으면 눈매·체형·선 굵기·색·비대칭·포즈·배율/위치를 유지했다. 기준 이미지가 없으면 동일 작업 내 파츠 간 디자인이 일치한다.
- [ ] **독립성:** 각 `isolated_parts/*.png`에는 해당 실제 부품만 그려져 있고, 속눈썹에 홍채가 붙거나 헤어에 얼굴이 섞이는 등 다른 부위 그림이 묻어나지 않았다.
- [ ] **고급 분리의 적정성:** 움직임·앞뒤 깊이·다른 가림·표정 변화가 다르면 처음부터 분리했다. 한 덩어리로 자연스럽게 휘는 가닥과 고정 무늬를 숫자 맞추기 위해 과분할하지 않았다.
- [ ] **숨은 면과 겹침:** 머리뿌리, 앞머리 밑 이마, 귀 뒤, 홍채 뒤 흰자, 입술 밑 입안, 턱 아래 목, 소매·팔꿈치·손목 및 옷 안감을 충분히 그려서 중립 합성에서 빈틈이 없다. 이는 **원화의 시각 점검**이며 회전 모델 테스트가 아니다.
- [ ] **얼굴:** 좌우 눈 흰자·홍채·속눈썹·눈썹·입술·입안·코 등 실제 필요한 원화를 독립 제작했다. 좌우를 대칭 복제하면 안 되는 고유 차이를 보존했다.
- [ ] **노출 방지:** **신체만**은 비선정적·불투명 기본 속옷을 착용하고 있다. 나체 베이스와 별도 속옷 교체 세트를 요청하지 않았다. 다른 자산 작업에 신체를 새로 포함하지 않았다.
- [ ] **투명 PNG/정렬:** 파일을 열어보았을 때 진짜 PNG/RGBA 알파이며, 파츠 바깥은 투명하고 같은 캔버스 크기·원점에 파츠가 정확한 위치를 차지한다. 그저 격자 배경을 그린 그림을 투명하다고 부르지 않았다.
- [ ] **합성 미리보기:** 합성본이 제출 PNG들을 실제로 합친 결과다. 눈/머리/목/팔/의상/장식의 위치 어긋남·틈·중복 선화·남은 마스크 잔상·비정상 비율이 없다.
- [ ] **파일 계약:** 실제 있는 PNG 이름을 중복 없이 `layer_order.txt`에 **캐릭터 본인 기준 L/R** 및 **뒤→앞 순서**로 적었고, 파일·미리보기·결과 ZIP 이름이 지시서와 일치한다.

## 품질 결함별 수정 규칙

- 눈이 찢어짐/홍채가 속눈썹에 붙음 → **눈 파츠만** 재생성·교체한 뒤 합성 재확인.
- 앞머리를 제거하면 이마에 구멍/옆머리가 뜸 → **피부·헤어뿌리 원화** 보강 후 합성 재확인.
- 입이 벌어질 때 입 안쪽이 빈 그림 → **입안·입술 피부** 원화 보강(그림 수준) 후 재확인.
- 손목/팔꿈치/목/의상 아래가 잘림 → **가려지는 안쪽 그림과 겹침 여유** 보강 후 재확인.
- 투명 배경이 불투명/파츠 위치가 틀림 → 해당 PNG의 알파·정렬을 고치고 미리보기와 파일 목록을 다시 생성.
- 일부러 없는 파츠를 숫자 채우려고 만들었음 → 그 파츠를 제거하고 목록과 미리보기를 다시 생성.

## 완료의 정직한 범위

여기서 '충족'은 이미지 AI가 **실제 생성·열람·비교 가능한 원화 및 파일 요구**에 한정한다. 실제 Cubism/ Inochi Creator에서의 동작과 사용자 취향의 완전한 객관적 증명은 이 과정으로 할 수 없다. 실행하지 않은 테스트를 PASS라고 쓰지 않는다. **임의의 품질 보고서/인증 문서 제출은 요구하지 않는다.**

## [결과 2D ZIP 필수 구조 게이트 — 2026-10-13]
- 실제 독립 파츠 PNG가 최종 완성된 뒤 `layer_order.txt`를 누락·중복 없이 파일명 대소문자까지 동일하게 유지한다. `isolated_parts/`의 모든 PNG만 정확히 한 번씩 뒤→앞 순서로 기록하며, 마스터·참고·합성 이미지는 기록하지 않는다.
- 최종 출력은 같은 ZIP 루트 또는 최상위 폴더 하나 아래의 `outputs/master.png`, `isolated_parts/<part_id>.png`, `layer_order.txt`여야 한다. 경로 접두·폴더 중첩/혼합 금지. 단순 이미지 ZIP에 `manifest.json` 자동생성 금지.
- 지시 ZIP의 `04_OUTPUT_FILES.md`에는 실행 가능한 Python 검증 코드가 내장되어 있다. 이미지를 생성하는 AI는 **압축 완료 후 그 실제 ZIP을 검사**하여 PASS가 확인되기 전에는 납품하지 않는다. 테스트 불가를 성공이라고 주장하지 않는다. 알파/캔버스와 원화 품질은 별도 점검한다.
- 파츠 변화가 있으면 실제 파일과 순서를 함께 바꾼다. 임의 정렬이나 비어 있는 가짜 PNG로 검사기를 속이지 않는다.
