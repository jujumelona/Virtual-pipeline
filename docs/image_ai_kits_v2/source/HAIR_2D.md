# 헤어만 — 지정된 한 헤어스타일의 고급 독립 원화

**신체·눈·입·의상·장식 세트를 새로 만들지 않는다.** 사용자가 준 기본 신체 얼굴/머리 크기와 좌우 비대칭에 맞춘다.

| 파츠 이름 예 | 그리기 기준 |
|---|---|
| hair_back_base.png | 뒤통수 뒤쪽 실루엣과 뿌리, 귀 뒤로 가려진 부분 |
| hair_back_layer_01.png | 뒤쪽 머리의 실제 서로 다른 깊이/흔들림 층 |
| hair_front_center.png, hair_front_L.png, hair_front_R.png | 앞머리 묶음이 서로 따로 흔들리는 경우 독립 생성 |
| hair_side_L.png, hair_side_R.png | 옆머리, 귀·얼굴 측면을 덮는 부위에 충분한 뿌리 |
| hair_lock_L_01.png, hair_lock_R_01.png | 독립 움직임이 있는 긴 가닥에만 추가. **긴 가닥을 억지로 여러 이미지로 자르지 않음** |
| hair_ahoge.png, hair_twin_L.png, hair_twin_R.png | **사용자 헤어스타일에 있을 때에만**. 머리카락 없는 스타일에 추가 금지 |

**먼저 요청된 헤어스타일 하나의 고품질 완성 원화**를 그린 뒤 실제로 움직일 부위만 추출한다. 단순히 원화에서 자른 조각만 내지 말고 머리뿌리·안쪽 색상·가려진 부분을 같은 화풍으로 추가 작화한다. 사용자 지정 헤어스타일 하나만 ZIP에 넣는다. 미리보기에서만 기존 얼굴 위에 합성할 수 있다.

### 자산 전용 고급 헤어
- 앞머리/옆머리 좌우/뒷머리를 큰 덩어리로 설계하고 실제 독립 흔들림이 있는 가닥만 분리한다.
- 정수리 모근의 방향·머리 실루엣·중간 가닥·테이퍼 끝, 안쪽의 짙은 그림자와 소재색 하이라이트가 흐름에 맞아야 한다.
- 귀 앞뒤·목 뒤·앞머리에 숨은 **머리카락 픽셀만** 추가로 그린다. 눈/피부/의복을 헤어 PNG에 넣지 않는다.
- 포니테일·트윈테일·아호게·장식은 실제 캐릭터 디자인에 있을 때만. 가닥 수를 늘리기 위한 의미 없는 분할 금지.
