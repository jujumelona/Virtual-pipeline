**먼저 요청된 헤어스타일 하나의 고품질 완성 원화**를 그린 뒤 실제로 움직일 부위만 추출한다. 단순히 원화에서 자른 조각만 내지 말고 머리뿌리·안쪽 색상·가려진 부분을 같은 화풍으로 추가 작화한다. 사용자 지정 헤어스타일 하나만 ZIP에 넣는다. 미리보기에서만 기존 얼굴 위에 합성할 수 있다.

### 자산 전용 고급 헤어
- 앞머리/옆머리 좌우/뒷머리를 큰 덩어리로 설계하고 실제 독립 흔들림이 있는 가닥만 분리한다.
- 정수리 모근의 방향·머리 실루엣·중간 가닥·테이퍼 끝, 안쪽의 짙은 그림자와 소재색 하이라이트가 흐름에 맞아야 한다.
- 귀 앞뒤·목 뒤·앞머리에 숨은 **머리카락 픽셀만** 추가로 그린다. 눈/피부/의복을 헤어 PNG에 넣지 않는다.
- 포니테일·트윈테일·아호게·장식은 실제 캐릭터 디자인에 있을 때만. 가닥 수를 늘리기 위한 의미 없는 분할 금지.

### [2026-10-13 정량 추천·측면/목 원화 소유권 hair]
[헤어/두상 회전] 정수리 모근에서 귀 앞·귀 뒤와 뒷머리의 가닥이 실제 어떤 깊이로 내려오는지 설계하고, 앞머리에 가려진 **머리카락 뿌리와 옆·뒷머리 안쪽만** 보완한다. 3/4 옆얼굴에서 가닥이 이마·귀·목 뒤로 휘어지는 모양을 원본 헤어스타일과 일치시킨다. 눈·귀·피부·목을 헤어 PNG로 만들지 않는다.

[헤어 측면 QA] 기준 몸체의 큰 눈/귀를 단지 위치 참조로 사용한다. 모근·앞/옆/뒤 머리 가닥의 원근·가림·알파 연속성과 정수리/뒷머리의 실제 볼륨을 확인한다. 없는 포니테일·아호게·핀을 강제하지 않고 목 피부나 옷 픽셀이 머리카락에 섞이지 않았는지 확인한다.

[공식 Live2D 참고] https://docs.live2d.com/ko/cubism-editor-tutorials/psd/ — 앞머리/옆머리/뒷머리의 파츠 분리, 가려진 뿌리 추가 작화. [개인 작가] https://tips.clip-studio.com/en-us/articles/8014 — 측면 두상 실루엣 참고. 목 피부와 눈의 크기·그리기 비율은 신체 ZIP의 계약이고 헤어의 필수 제작 규격이 아니다.

**재배치 규칙:** 위 기술은 자산 hair 원화에만 적용한다. 모드별 상세 차이는 `source/FACE_NECK_GEOMETRY_GUIDANCE.json`으로 관리하고 실제 납품 ZIP에 각각 적용한다.

### 02_ADVANCED_PARTS.md에 반영할 hair 전용 지침
**[헤어만/모근·그림자 소유]** 완성 헤어 원화에서 뿌리 위치가 두피 곡면을 따라 앞·옆·뒤로 연결되는지를 먼저 판단하고 실제 독립적으로 흔들리는 가닥만 분리한다. 눈/피부를 새로 만들지 않되, **앞머리가 얼굴에 만드는 그림자가 실제 디자인에서 필요하고 별도로 움직여야 한다면** 피부 베이스에 굽지 않고 **헤어 소유의 선택적 별도 투명 그림자**로 계획한다. 필요 없으면 만들지 않는다. 헤어 자체의 뿌리·가닥·뒷면 명암은 해당 헤어 PNG에만 포함한다.
