# 움직임 단위 원화와 회전 대비 그림 지침

**부위 ID는 본 프로젝트의 파일명 예시**이며 Live2D 공식의 강제 총수·명령어 목록이 아닙니다. 캐릭터의 디자인과 실제 움직임에 맞게 가감하십시오. PNG 파일 수와 이미지 생성 요청 수는 다릅니다. L/R은 캐릭터의 왼쪽/오른쪽입니다.

| 영역 | 추천 독립 PNG 이름 | 그려야 할 내용 |
|---|---|---|
| 얼굴 피부 | `face_skin.png` | 눈·입·머리카락이 없는 피부 베이스; 앞머리 아래 이마, 양 볼, 턱까지 |
| 귀·코 | `ear_L.png`, `ear_R.png`, `nose.png` | 실제 디자인에 있고 독립으로 움직일 필요가 있을 때 |
| 헤어 | `hair_back.png`, `hair_side_L.png`, `hair_side_R.png`, `hair_front.png` | 서로 섞이지 않는 앞/옆/뒤 머리; 흔들릴 가닥은 필요시 추가 |
| 눈썹 | `brow_L.png`, `brow_R.png` | 각 눈 위에 독립 부착 |
| 왼눈 | `eye_L_white.png`, `eye_L_iris.png`, `eye_L_lash.png` | 흰자/홍채/속눈썹 각 독립. 홍채가 이동해도 흰자가 빈 구멍 없이 유지 |
| 오른눈 | `eye_R_white.png`, `eye_R_iris.png`, `eye_R_lash.png` | 좌우의 원화 디자인 차이 유지 |
| 입 | `mouth_inside.png`, `mouth_upper.png`, `mouth_lower.png` | 실제 채색된 입안·윗입술·아랫입술. 각기 독립 |
| 목 | `neck.png` | 턱 아래 안 보이는 윗목까지 연장 |
| 몸통 | `torso.png` | 팔·목 아래 가려진 옷/몸통까지 연장 |
| 왼팔 | `arm_L_upper.png`, `arm_L_forearm.png`, `hand_L.png` | 어깨·팔꿈치·손목 연결 안쪽을 충분히 그림; 소매 포함 |
| 오른팔 | `arm_R_upper.png`, `arm_R_forearm.png`, `hand_R.png` | 동일 |
| 의상·장식 | `collar.png`, `ribbon.png` 등 | **독립으로 움직이는 실제 장식만** 추가, 고정 프린트는 굳이 분리하지 않음 |
| 전신 추가 | `skirt.png`, `leg_L.png`, `leg_R.png`, `shoe_L.png`, `shoe_R.png` 등 | 전신을 요청한 경우 실제 복장에 맞춰 분리 |

**그리는 기준:** 함께 움직이는 것은 묶고, 따로 움직이거나 뒤쪽 그림이 새로 드러나는 부위는 나눈다. 무조건 일정한 수를 채우려고 쪼개지 않는다.

**기준 이미지와 파츠 사이의 구조:** 얼굴 피부는 앞머리가 사라져도 그림이 이어지고, 눈 흰자는 홍채가 움직여도 뒤가 남으며, 입안은 닫힌 입술 뒤에 가려질 수 있어야 한다. 팔을 떼면 몸통 옷감이 이어져야 한다.

**회전:** 공식 기본 Angle X/Y/Z 설정 예시는 -30~+30 범위다. 이 숫자는 이미지 장수 요구가 아니며, **이미지 AI에게 모델 움직임을 구현하라고 하지 않는다.** 필요한 숨은 그림만 준비한다. 좌우 3/4 참고 그림은 유용하지만 필수 개수는 정해지지 않았다.

**눈에 띄는 실패 예시:** 속눈썹 그림에 홍채가 붙음, 뒷머리 그림에 앞머리/얼굴이 붙음, 목·소매 밑이 잘려 있음, 입안 파일이 텅 비어 있음, 기준 그림과 좌우 3/4 인물이 다름. 이런 경우 해당 **그림만 다시 그리기**.

참고할 공식 예제와 이미지 다운로드 링크는 `OFFICIAL_LINKS.md`에 정리했다.
