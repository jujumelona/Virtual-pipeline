# 이미지 제작을 위한 Live2D 공식 참고

**실제 이미지/PSD 예제를 살펴보고 파츠가 어디서 나뉘는지 참고하는 용도**다. 원문 링크가 열리지 않는 AI에게 읽었다고 주장하도록 요구하지 않는다. 필요하면 사용자가 공식 사이트에서 예제를 내려받아 적법하게 이미지로 첨부한다.

| 공식 자료 | 링크 | 원화 AI에게 필요한 내용 |
|---|---|---|
| **모모세 히요리 등 일러스트 가공 예제** | https://docs.live2d.com/en/cubism-editor-tutorials/psd/ | 실물 분리 PSD 및 분리된 머리·눈·입·몸 그림 예시 |
| **소재 분리 방법** | https://docs.live2d.com/en/cubism-editor-manual/divide-the-material/ | 움직임별 그림 분리와 보이지 않는 부위 보강 |
| **PSD 원화 주의점** | https://docs.live2d.com/en/cubism-editor-manual/precautions-for-psd-data/ | 나중에 레이어가 될 독립 그림을 준비할 때 참고 |
| **공식 모델 예제 다운로드** | https://www.live2d.com/en/learn/sample/ | 완성 캐릭터의 표정·헤어/얼굴 구조 참고 |
| **표준 파라미터** | https://docs.live2d.com/en/cubism-editor-manual/standard-parameter-list/ | Angle X/Y/Z는 모델 회전용 파라미터임을 이해 |
| **공식 FREE/PRO 차이** | https://www.live2d.com/en/cubism/comparison/ | 제작 도구 제약 배경 참고, 이미지 생산 장수 제한 아님 |
| **공식 무료 자료 이용 조건** | https://www.live2d.com/eula/live2d-free-material-license-agreement_en.html | 공식 예제 파일 재사용·재배포 시 이용 조건 확인 |

**요약:** 함께 움직이는 그림을 묶고 서로 다르게 움직일 그림은 분리한다. 가려진 피부·머리카락 뿌리·목·몸통 연결부를 완성해서 그린다. Live2D 공식은 **AI가 총 8장/9장 그림을 그리거나 60개 조각을 만들라는 기준을 제공하지 않는다**.

**포함 그림:** ZIP에 들어 있는 `visual_references/*.svg`는 이 프로젝트의 자체 개념도이며 **공식 Live2D 원화 예제 자체가 아니다**. 공식 예제의 이미지/PSD는 위 공식 URL에서 라이선스를 확인하고 획득해야 한다.
