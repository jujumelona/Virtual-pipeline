# 대형 이미지 AI에게 직접 주는 제작 의뢰

이 ZIP은 **Live2D 버추얼 캐릭터 이미지 원화 생성** 전용 지시서입니다. **설명만 쓰지 말고 실제 이미지를 그려 파일로 저장하십시오.** 첨부 ZIP의 나머지 문서와 공식 URL은 그림을 어떻게 그릴지 참고할 자료입니다.

## 1. 캐릭터 정하기

사용자가 같은 대화에서 알려준 성별/체형/헤어/의상/색감/스타일/소품, 상반신·전신 범위를 우선합니다. 아직 캐릭터 그림이 없다면 먼저 `outputs/master.png`를 생성합니다. 이미 기준 그림을 받았다면 그 이미지를 `outputs/master.png`로 사용합니다.

모든 개별 파츠를 만들 때 **기준 master 실제 이미지를 매번 시각적 참조로 사용**하십시오. 얼굴 비율, 양쪽 눈매, 홍채색, 옷깃, 장신구, 좌우 비대칭, 선 굵기와 채색을 보존하십시오. 정면/중립 자세가 기본입니다.

## 2. 움직이는 파츠를 실제 원화로 만들기

`PARTS_ARTWORK.md`의 부위 목록을 참고해 **움직임이 다르면 그림을 분리**하십시오. 예: `eye_L_lash.png`에는 속눈썹만, `eye_L_white.png`에는 눈 흰자만, `eye_L_iris.png`에는 홍채만 그리십시오. 앞머리와 뒷머리도 서로 섞이지 않아야 합니다.

**금지:** master 이미지를 자르거나 마스킹만 해서 '파츠 완성'이라고 제출하는 것. 눈·소매·머리카락이 잘렸을 때 **뒤에 가려진 형태를 별도 생성/보완**해야 합니다. 보이는 부분의 원본 픽셀을 일부 보존하는 것은 괜찮지만, 숨은 영역을 그리지 않고 종료하지 마십시오.

머리카락 뒤의 이마·귀·볼, 얼굴 뒤의 목, 홍채 뒤 흰자, 입안, 팔 아래 몸통·옷감, 어깨·팔꿈치·손목의 겹치는 부분을 그려 **움직임용 재료로서 끊기지 않게** 하십시오.

## 3. 이미지 생성과 파일 저장 방법

- 먼저 기준 원화, 이어서 머리카락/얼굴/눈/입/몸통/팔/장식 순서로 생성하십시오. 부위별 요청으로 **한 장씩 생성**해도 되고, 여러 작은 부위를 하나의 **비중첩 파츠 시트**로 생성해도 됩니다.
- 시트에서 만든 부품도 최종 결과는 **독립된 PNG 한 파일씩** 저장하십시오. 눈 시트 한 장이 여러 독립 PNG를 대신하지 않습니다.
- 가능한 경우 **진짜 알파 투명 PNG(RGBA)**로 출력하십시오. 바둑판 배경이 그려진 JPG/PNG나 단색 배경을 투명으로 표기하지 마십시오.
- **각 파츠 PNG는 master와 같은 캔버스 픽셀 크기**이고, 해당 파츠가 **원래 캐릭터상 위치**에 놓이며 나머지는 투명하도록 저장하십시오. 작은 파츠 이미지는 파일 저장 도구로 같은 크기의 투명 캔버스에 올릴 수 있습니다. 원래 위치를 알 수 없다면 정합되었다고 주장하지 마십시오.
- **L/R은 캐릭터 자기 기준**입니다.
- `layer_order.txt`에 생성한 독립 PNG 파일을 **뒤쪽에서 앞쪽 순서로 한 줄에 하나씩** 적으십시오. 이건 이미지 파일들의 단순 목록으로, 생성 AI가 할 수 있는 작업입니다. 실제 캐릭터 가림 관계를 보며 정하십시오.
- 이 폴더에 들어가는 다른 문서를 납품 ZIP에 다시 복사할 필요는 없습니다.

## 4. 회전에 쓰일 그림

Live2D에서 `Angle X/Y` 변형을 수행하는 것은 **후속 리깅 작업**입니다. 이미지 작업에서는 회전/기울임 때문에 드러날 피부·귀·헤어뿌리·목·소매 안쪽 그림을 준비하십시오. 필요한 경우 master에 맞는 좌·우 3/4 얼굴 **참고 이미지**를 `reference_views/`에 더 그릴 수 있습니다. 이것은 실제 모션 파일이 아닙니다. 특정 '회전 9장'이나 '측면 7장'을 만들라는 요구는 아닙니다.

## 5. 최종 납품

`OUTPUT_FILES.md` 규칙대로 실제 PNG와 `layer_order.txt`가 든 `Live2D_Character_Artwork.zip` 하나를 만드십시오. **PSD, .moc3, .model3.json, 리깅/테스트 로그, 임의 합격 인증서, 복잡한 manifest JSON을 만들 필요가 없습니다.** 이들은 이미지 생성 작업 범위가 아닙니다.

**작업 시작:** 사용자가 설명한 캐릭터에 맞게 master부터 실제 이미지를 생성하고 이어서 그림 파츠를 준비하여 파일 ZIP으로 전달하십시오.
