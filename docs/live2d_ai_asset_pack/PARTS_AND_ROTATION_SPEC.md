# 대형 이미지 AI를 위한 Live2D 파츠/회전 제작 계약

이 목록은 공식 튜토리얼의 **움직임 단위 분리 원칙**을 컴퓨터가 읽기 쉬운 파일 ID로 만든 프로젝트 명세다. 공식이 아래 모든 파츠의 개수/파일명을 필수로 지정한 것은 아니다.

**좌우 L/R은 캐릭터 자기 기준**으로 고정하며 화면 좌우와 혼동하지 않는다. 각 파츠는 동일 master 좌표계 PNG거나 크롭 위치를 manifest에 기록한다.

| 움직임·분리 | 프로젝트 part ID 예시 | 이미지 AI가 실제로 만들 것 |
|---|---|---|
| 얼굴과 귀 | face_skin, nose, ear_L, ear_R | 머리 아래까지 이어지는 얼굴 피부, 필요시 귀/코 분리 |
| 앞·좌우 옆·뒤 머리 | hair_front, hair_side_L, hair_side_R, hair_back | 뿌리와 가려진 피부가 드러나도 연결되는 머리카락, 독립 가닥은 추가 |
| 눈썹 | brow_L, brow_R | 좌우 따로 |
| 좌우 눈 | eye_L_lash, eye_L_white, eye_L_iris, eye_R_lash, eye_R_white, eye_R_iris | 속눈썹/흰자/홍채 각각 독립. 홍채 뒤 흰자 완성 |
| 입 | mouth_upper, mouth_lower, mouth_inside | 입술 위·아래, 입 안. 닫을 때 입안을 숨길 수 있음 |
| 목 | neck | 고개 상하 움직임에 충분한 위쪽 연장 |
| 몸통 | torso | 팔과 머리 밑에 가려진 옷/몸통의 이어진 영역 |
| 왼팔 | arm_L_upper, arm_L_forearm, hand_L | 상완·전완·손의 독립 이미지. 소매/관절 접합부 보존 |
| 오른팔 | arm_R_upper, arm_R_forearm, hand_R | 위와 동일 |
| 의상/장식 | collar, ribbon, 실제 소매/장식 | 독립으로 움직일 부위만 추가. 고정 의상 무늬까지 모두 분리하지 않음 |
| 전신일 때 | skirt, leg_L, leg_R, shoe_L, shoe_R 등 | 실제 복장에 맞는 하체/신발. 상반신이면 불필요 |

**파츠 시트 규칙:** 한 시트에 여러 파츠를 놓는 것은 생성 호출 수를 절약하는 방식일 뿐이다. 비중첩 rect와 각 파츠의 원래 master 배치 좌표를 명시하고, 시트의 각 part ID에 대해 isolated_parts/{part_id}.png를 별도 저장해야 한다. 좌표를 알 수 없다면 단독 PNG로 다시 생성한다. 라벨 문자를 스프라이트에 섞지 않는다.

## 회전 준비

- 공식 표준 **ParamAngleX: -30/0/+30 (화면 오른쪽 +)**, **ParamAngleY: -30/0/+30 (위를 바라보는 +)**, **ParamAngleZ: -30/0/+30**.
- **X -45~+45** 등 넓은 범위는 공식 확장 예시이지만 별도 메시/디포머/리깅 검증이 필요. **±90 측면 자동 생성 보장 금지**.
- **X/Y 3×3 키폼은 이미지 9장 뜻이 아님**.
- 앞머리 아래 이마/볼, 옆머리 아래 귀, 뒤통수 실루엣, 얼굴 밑 목, 홍채 밑 흰자, 입안, 어깨 아래 의상·몸통 등 **움직이면 드러날 원화**를 충분히 그린다.
- 별도 reference_views/head_3quarter_L.png 등은 필요 시 **가이드 이미지**로 생성 가능. 실제 리깅 파츠·키폼은 아님. 생성 장수와 각도는 공식 고정값 없음.

## 점검

PNG가 존재한다고 움직임이 구현된 것은 아니다. Cubism/PSD2Live에서 실제 렌더링하여 기울임/회전/눈 깜빡임/입/팔의 빈 공간·가림·왜곡을 확인해야 한다. 실행하지 않은 단계는 NOT_TESTED로 표시한다.
