# DEMO 결과 재제작 지시문 — GPT/Gemini에 그대로 전달

**첨부된 Live2D_AI_DEMO_Asset_Pack은 PNG 수량만 충족한 시연 결과이며 원화/리깅 완료가 아니다.**

`PRODUCTION_ACCEPTANCE_V2.md`와 공식 자료, 파츠 명세를 먼저 확인한다. **그럴듯한 설명문이 아니라 실제 수정한 이미지 파일과 ZIP을 납품**하라.

1. 마스터는 캐릭터 디자인의 기준이다. 기존에 마스터 픽셀을 마스킹해 만든 파츠 29개를 새로 그린 원화로 오인하지 말라. 보이는 픽셀 보존은 허용하되 **움직일 때 드러나는 부분을 실제로 새로 그려 완성**하라.
2. `eye_L/R_lash`에서 홍채·흰자 픽셀을 제거하고 **속눈썹만** 따로, 흰자·홍채도 각각 완전한 그림으로 제작하라. `hair_back`은 앞머리·얼굴이 섞이지 않은 뒷머리 그림으로 다시 제작하라.
3. 실제 입안(`mouth_inside`)을 완성하고 윗입술/아랫입술과 독립으로 분리하라. 목·귀·이마·머리카락 뿌리, 팔·소매 뒤쪽의 숨은 영역을 실제 그려라.
4. 팔 좌우 상완·전완·손을 각각 그린 뒤 관절을 움직였을 때 연결이 끊어지지 않도록 **겹침 여유**를 넣어라. 마스터의 의상 디자인과 다른 소매를 만들어내지 말라.
5. 시트 생성은 허용하지만 파츠별 PNG를 **각각 독립 파일**로 내보내고 원본 캔버스 위치와 시트 내 rect를 나누어 기록하라.
6. 회전 참고화를 납품하는 경우 master와 좌우 3/4 그림을 비교한 시각 증거를 제출하라. 눈매·헤어·의상이나 좌우 장식이 달라졌다면 **REJECTED 후 재생성**하라.
7. 실제 레이어 PSD를 만들 수 있다면 조립·재열기·합성 검증하고 내보내라. 환경에서 PSD2Live/Cubism을 **실제 실행할 수 있다면** .moc3/.model3.json/텍스처와 로그까지 첨부하라. 도구가 없다면 PSD/리깅을 완료했다고 주장하지 말고 `NOT_DELIVERED`로 표기하라.
8. `quality_review.md`와 `manifest.json`에 각 파츠가 generated/redrawn/edited_with_underpaint/extracted_only 중 무엇인지, 새로 그린 영역, 시각 검수 내용, 실제 A/B/C/D 납품 등급을 기록하라.

**필수 미리보기:** `previews/neutral_composite.png`, `previews/parts_contact_sheet.png`, 회전 참고화 제출 시 `previews/reference_identity_comparison.png`. 실제 파일이 포함된 ZIP을 생성하고 열어서 확인한 후 제출하라.

**중요:** 요구하는 것은 29개 파일명의 충족이 아니라 **실제 움직일 수 있도록 그려진 파츠 원화**다. 아직 못 한 단계는 실패/미검증으로 보고하라.
